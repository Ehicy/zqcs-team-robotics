使用边界

请使用 Android Chrome，并通过 HTTPS 打开本页。普通手机局域网 HTTP 地址无法使用 Web Bluetooth；localhost 仅指当前设备本机。

离开页面、锁屏、失联或页面调度停顿后都会锁定。重新连接必须再次手动解锁。软件停止不代替整车物理断电；车体停止距离需实测。
