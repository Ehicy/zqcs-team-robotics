# O 形麦轮摇杆与肩键调速（2026-09-30）

**2026-10-02 当前操作已变更：**左杆方向与幅度连续控制平移 PWM，右杆方向与幅度连续控制旋转；L1/R1 不再调速。上电实际输出0、默认上限100%；松杆/START立即撤驱动，START后松键回中再推杆即可行驶。较早开环版已烧录并独立读回一致，见 [调优与下载记录](MOTOR_TUNING.zh-CN.md)。最新试验源码另加更快响应、横移人工辅助学习和 Flash 保存，尚未烧录，优先看 [当前操作](DRIVER_CALIBRATION.zh-CN.md)。本文轮位、极性和 O 形混合仍为基础，横移增益另见当前源码；以下肩键操作、源码导读和旧地址只用于追溯9月30日版本。

## 历史操作（2026-09-30）

| 操作 | 结果 |
|---|---|
| 上电／复位 | 速度档0%，电机输出零；模拟模式、松开按键且控制轴回中后使能，须R1加档才可行驶 |
| 左摇杆上下／左右／斜向 | 前后／横移／斜移，方向以车头为准 |
| 右摇杆左右 | 俯视逆时针／顺时针旋转；上下未绑定 |
| L1（左上肩键） | 每按一次减10%，最低0%；0%停止 |
| R1（右上肩键） | 每按一次加10%，最高100% |
| 长按肩键／同按L1与R1 | 长按仅调一次；同按不调速度 |
| START | 全停、速度清零、按键历史及灯态重置；松开按键并回中后使能，须重新加档 |
| 回中／无效帧／数字模式 | 输出零；异常恢复须松开按键并回中 |
| PC13 用户灯 | 0～60%灭，70～100%闪烁；严格大于60%才闪，POWER灯不受程序控制 |

百分比表示最大轮PWM占空比，不是实测转速或电流。当前为开环PWM调档，
尚无电流检测或软件过载保护。出死区（120～136以外）后，推杆深浅不改变速度；
左杆保留方向分量比例，右杆只取左/右。混合平移和旋转时四轮统一缩放，
每一轮都不超过当前速度档。重新上电/复位或START均重置0%，须用R1加到10%起步。
START在有效数字41模式中也会执行全停清零；肩键调速和摇杆行驶仍要求模拟73。

## 用户确认的轮位

| 电机 | 原测试键 | 轮位 | GPIO／通道 | 电气正向实际结果 | 小车极性补偿 |
|---|---|---|---|---|---|
| 1 | × | 左后 | PA0/PA1，① A | 后退 | -1 |
| 2 | ○ | 右后 | PA2/PA3，① B | 后退 | -1 |
| 3 | □ | 左前 | PA6/PA7，② A | 前进 | +1 |
| 4 | △ | 右前 | PB0/PB1，② B | 前进 | +1 |

电气正向是IN1=PWM、IN2=0，机械正向是让车前进；电机线保持当前接法。
用户确认滚子从车顶看为O／菱形。本文用俯视定义，避免资料从底部观察造成X/O名称相反。

```text
              车头 ↑
       左前 /          \ 右前
       左后 \          / 右后
```

F=前进、L=左移、T=逆时针旋转的轮输出分量，先算机械正向，再补偿电气极性：

```text
左后 = F - L + T
右后 = F + L - T
左前 = F + L + T
右前 = F - L - T
```

俯视O形旋转杠杆为半轴距减半轮距。暂按前后轮心距离大于左右轮心距离，
`MOTOR_O_ROTATION_SIGN=+1`；实际轮心尺寸尚未测量。若旋转左右相反，
先核对滚子俯视方向和轮心距离再调该常量。接近正方形的O形轮距会削弱旋转能力。
这里是开环PWM调试，没有轮速闭环或世界坐标朝向测量。

## PS2 代码核对与阅读

已重新检查 `D:\BaiduNetdiskDownload\手柄控制\1 手柄程序参考代码\PS2无线手柄程序-STM32F1.zip`
内 `Driver/ax_ps2.c`、`ax_ps2.h`，并逐项核对仓库 `ps2.c`、`ps2.h`。

- 九字节请求为 `01 42 00 00 00 00 00 00 00`，低位先传，16µs半周期。
- 模式在索引1，固定标志在索引2（5A）；按键低有效，读取后取反。
- `btn2` bit2=L1、bit3=R1，完整按键掩码0400/0800；不是L2/R2。
- 右摇杆左右/上下为索引5/6，左摇杆左右/上下为索引7/8。
- 参考包GPIO为PA4～PA7，当前继续用PB14=DAT、PB15=CMD、PB12=CS、PB13=CLK。
- 数字41没有模拟轴；小车只在模拟73下驱动，压感79暂未支持。

配套《PS2无线手柄使用指导手册V1.0.3》第12页建议按MODE调到手柄红绿灯都亮；
第4页的配对灯态不能单独证明摇杆有效，以板上 `control_mode=73` 确认。
STM32读取摇杆无需一直按L1/R1，肩键只调速度。

从 `main.c` 的 `control_step()` 看起：读取PS2、拒绝无效模式、处理START和回中，
再由 `buttons_process()` 找出按下边沿，`on_button_pressed()` 调速。
`motor.c` 归一化摇杆方向，按O形混合、限幅、乘速度及极性。
`pwm.c` 写TIM2/TIM3，正负号选择驱动输入，0/0为滑行停机。
默认速度、步长、上限、闪灯阈值与旋转符号在 `motor.h`。

调试可看 `speed_percent`、`control_mode`、`control_ready`、`ps2Data`、`control_loops`，
地址以本次ELF符号表为准。

`main.c` 中 `speed_led_step()` 在每次控制更新后运行；速度严格大于60%时立即亮灯，
每40次轮询切换一次亮灭（约0.5秒），回到60%及以下立即灭。没有额外阻塞延时；
数字模式或坏帧期间继续显示已保存的速度档，灯态不代表车轮在运动。START会清零并灭灯。
