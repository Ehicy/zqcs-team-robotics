# 横移补偿靠近原始状态（2026-10-02）

用户反馈前85/后100的横移补偿让偏移更严重。本版把前后相对强弱调换，同时把差值从15缩小到5个百分点：**前100%、后95%**。这是供实车比较的起点，尚未确认能改善偏航。

| 项目 | 新设置 |
|---|---|
| 满幅起步 | 200个百分点/秒，0到100%约0.5秒 |
| 摇杆曲线 | 左杆25%、右杆50%三次混合；[映射说明](PAD_MAPPING.zh-CN.md) |
| 前/后轴横移分量 | 100/95，原始无补偿为100/100 |
| 人工辅助学习 | 速率系数2.0，每次按住SELECT最多改5个百分点 |
| Flash记录版本 | 2；版本1记录保留但不加载 |

减速率仍为1000个百分点/秒，换向零输出等待仍为40ms。满幅0.5秒是PWM斜坡时间，不是测出的车速或机械起步时间；较小PWM目标提前到达。松杆、START、无效/数字帧仍立即撤输出，恢复行驶须回中松键。上限100%，普通驾驶不学习。

## 最简单的比较步骤

1. 烧录后先不用SELECT训练，左杆纯左/纯右各走一小段，右杆保持回中，比较100/95效果。
2. 若仍偏得更厉害，停车回中，**按住SELECT，轻按×，再松开两键**，恢复原始100/100。回中松键至少2秒后自动保存；两次写入尝试最少间隔30秒，成功提示双闪。
3. 在100/100基线上若想每次只减后轴5点：停车按SELECT+方向键↓；恢复后轴用SELECT+方向键↑。减前轴用SELECT+□，加前轴用SELECT+△。每按一次执行一次，长按不重复，范围50～100。
4. 手动值比较明确后再考虑训练：按住SELECT纯横移，用小幅右杆抵消车身偏转；稳定0.6秒后缓慢调整，单次最多5点。松SELECT即结束本次训练；松杆松键停车后保存。

SELECT+○在摇杆回中时请求保存，也遵守30秒间隔；START停车并保留校准。POWER电源灯不受程序控制，PC13用户灯行驶中仍在实际PWM大于60%时闪烁。

## 本次更改的范围

保持O形混合、轮位和后轮电气极性。左/右横移的轮子方向没有反转，只改变前后轴横移项的比例。纯前后和纯右杆旋转不使用这两项横移比例；用户反馈的“只推右杆绕尾部旋转”仍需要另行核对，不能认为本次补偿已解决。

旧Flash中有效的版本1参数也不会覆盖新默认值。本版不在开机时自动写默认值，旧记录仍在参数页；下一次人为保存或参数变化后停车自动保存时追加版本2。以后版本2保存值优先于默认100/95；SELECT+×恢复100/100。下载HEX不要选择全片擦除，历史参数页已预留在代码区之外。
