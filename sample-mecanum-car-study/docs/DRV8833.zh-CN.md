## 接线与输出

| 电机 | 模块通道 | IN1 / IN2 | 定时器通道 |
|---|---|---|---|
| 1 | DRV8833① A | PA0 / PA1 | TIM2 CH1 / CH2 |
| 2 | DRV8833① B | PA2 / PA3 | TIM2 CH3 / CH4 |
| 3 | DRV8833② A | PA6 / PA7 | TIM3 CH1 / CH2 |
| 4 | DRV8833② B | PB0 / PB1 | TIM3 CH3 / CH4 |

PS2：DAT=PB14（输入）、CMD=PB15、CS=PB12、CLK=PB13，现已与根目录 PROJECT.md / 信号接线图一致。旧代码的 PS2 接法不能继续照用。TIM4 与 PB6/PB7 留给后续舵机；PA13/PA14 保留 SWD。

pwm_set1～4 的参数现在是带符号的 -1～1，超过范围限幅、NaN 归零。正向 PWM/0，反向 0/PWM，零输出与 motor_stop 均为 0/0 滑行，不是主动刹车；依据 [TI DRV8833 数据手册第9页表1/2](https://www.ti.com/lit/ds/symlink/drv8833.pdf)。每对输入先清旧方向，再给新方向；CCR 无预装载，因此清零无需等待更新事件。此写入顺序不等于电机已经减速，也不保证限制快速反转电流。

motor_init 内部初始化 GPIO 和 TIM2/TIM3；八个输入预置低，比较值清零后才切为复用 PWM。默认定时器映射。正常 HSE=8 MHz、系统72 MHz条件下，PSC=0、ARR=3599，PWM 为20 kHz。若晶振启动失败退回8 MHz，实际频率随时钟降低。20 kHz 是可修改的调试起点，低速起转和温升须验证。

两板 nSLEEP 运行时必须为高；当前依赖模块硬件上拉/使能，不控制 PA8。照片模块的 STBY 对应该使能脚，已指导接 3.3V。电机1～4依次为左后、右后、左前、右前；后轮极性补偿 -1，前轮 +1。整车平移和旋转仍需落地验证。

2026-10-02 用户选择本次测试将两板 VM 从 5V 改到两串电池正极（满电8.4V），先移除 VM 原5V正极线；用户已反馈实机行驶，TT 过压耐受、电流温升和实际端电压仍未验证。STBY 保持3.3V，主控和 PS2 转接板保持规定的低压供电。每块板任选一个标为 GND 的端子接地即可，电池负极、两板和 STM32 必须共地。接电与实际安装情况不能由烧录结果代替。

电脑测试：

```powershell

python tests/run_tests.py
```

测试覆盖八通道初始零输出与引脚分配、双定时器周期、四对输入独立性、正反向/零值/满量程/越界/NaN/无穷值、每次寄存器写入后的双输入互斥、换向及停车；保留256个回中判断、2197组混合、PS2逐位模拟与异常恢复测试。主机模拟不验证真实波形、电流和机械运动。

实车按顺序：
1. 架空轮子，上电确认无误转；手柄推杆上电不能启动，回中并松开按键后才能控制。
2. 先检查PS2模式0x73，再逐轮确认编号与正反方向；核对8路PWM及停止时低电平。
3. 低幅度测试前后、横移和转向，逐步加负载观察温升和供电；避免直接高速反转。
4. 测试关手柄、断DATA、断接收器电源、距离失联。无效帧会停车，但接收器重复返回有效旧帧仍无法识别无线失联。
5. 本次未实现夹爪、独立看门狗或故障硬件停机；夹爪TODO保留，其他限制仍未解决。
