## 起步怎样变化

从零输出开始，四轮共用五次 S 曲线 `S(x)=10x³−15x⁴+6x⁵`；两端变化较缓，中段加速较快。恒定满幅目标下，0.5 秒达到 100% PWM。

| 起步时间 | 满幅目标的 PWM |
|---|---|
| 100 ms | 约 5.8% |
| 200 ms | 约 31.7% |
| 250 ms | 50% |
| 400 ms | 约 94.2% |
| 500 ms | 100% |

小幅目标的起步时间按幅度缩短，最少 80 ms；例如 10% 目标用 80 ms。四轮共用幅度包络和插值比例，恒定目标下保留四轮比例。起步中改变方向或幅度不会重启计时，另外限制变化斜率；这种情况下不保证恰好 0.5 秒达到新的目标。

主循环卡顿后，一次最多推进 20 ms 的起步进度。直接把摇杆推到相反方向仍先共同减速至零，等待至少 40 ms，再按 S 曲线起步。

## 松杆与 START 怎样停车

正常模拟帧下，两杆控制轴都回中，或按 START：

1. 清空运动目标，先撤驱动 20 ms。
2. 各轮按此前输出的相反方向，输出此前 PWM 的 10%，名义窗口 30 ms。例如此前 80%，反向脉冲为 8%；满幅时最高 10%。此前为零的轮子不补反转脉冲。
3. 两个驱动输入都置高，短路制动 100 ms，然后回到双输入为零的滑行状态。

此前最大输出低于 30% 时，跳过反转脉冲，直接短路制动。静止时没有脉冲。持续松杆或长按 START 不会延长或重复急停。

松杆后很快再推杆，会在停车阶段结束后接受新目标，再按 S 曲线启动。START 会额外复位操作状态：停车完成、松开所有按键并回中后，重新推杆才行驶；保留横移校准参数。

无效帧、数字模式、非法数值、输出上限设为零以及 Flash 擦写前，直接写双输入 0/0 并取消急停，不产生反向脉冲。有效的数字模式 START 也只撤驱动。

这些时间由主循环推进，会有约一个轮询周期的误差。如果进入反转阶段前主循环已经错过整个反转窗口，程序跳过脉冲。**没有独立硬件定时关断：调试暂停或主循环停滞时，最后的 PWM 可能保持。** ST-Link 暂停、复位和下载前须断开两块 VM 正极线。

DRV8833 的输入 1/1 使两个电机输出都为低电平，短接电机绕组以制动；它不是将电源正负极短接。输入 0/0 为高阻滑行。依据：[TI DRV8833 数据手册第 9 页](https://www.ti.com/lit/ds/symlink/drv8833.pdf)。一般的加减速与换向等待调参可参考 [Pololu 官方控制器文档](https://www.pololu.com/docs/0J77/5.2)，其控制器的限流功能不能当成本车已有功能。

## 如何试车

下载完成后，先关电源，接回两块 VM，再上电；摇杆回中、按键松开后，小幅向前推杆并松开，检查能否停车。低 PWM 测的是短路制动；此前输出达到 30% 后才会加反转脉冲。再单独比较 START 停车，确认松键回中前不能重新启动。

本车两串电池的实际电流、温升和车轮停车时间尚未测量。反转 PWM 小不等于电流受限；如果停车后向后蹿或冲击明显，先把 `MOTOR_STOP_REVERSE_PERCENT` 减为 5，或者改为 0 只用短路制动，不应直接增加反向力度。

参数在 `hardware/Inc/motor_tuning.h`：

```c
#define MOTOR_STARTUP_CURVE_MS          500U
#define MOTOR_STARTUP_MIN_MS            80U
#define MOTOR_STARTUP_MAX_RATE          375U
#define MOTOR_STOP_REVERSE_PERCENT      10U
#define MOTOR_STOP_REVERSE_MIN_PERCENT  30U
#define MOTOR_STOP_COAST_MS             20U
#define MOTOR_STOP_REVERSE_MS           30U
#define MOTOR_STOP_BRAKE_MS             100U
```

本次保留左杆 25% / 右杆 50% 三次混合映射、前 100 / 后 95 横移默认值、版本 2 Flash 校准格式和 SELECT 人工辅助学习。行驶输出严格超过 60% 时闪灯；这不是电流或温度报警。
