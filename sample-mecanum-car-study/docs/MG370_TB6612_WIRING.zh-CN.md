# MG370＋两块 TB6612FNG＋STM32F103C8T6 接线规划

> **历史草案，已被2026-10-03方案替代。** 本文记录早期单板、双输入PWM和全中断编码器接法；当前采用主控F103＋底盘F103，底盘独自控制两块TB6612及四个13PPR霍尔MG370。请以[最新逐接口接线方案](DUAL_F103_CHASSIS_WIRING.zh-CN.md)为准，不混用本文的GPIO、STBY或编码器接线。

更新：2026-10-02。用户已确认两块普通 TB6612FNG 双路板，电机为 MG370、尚未购买。手机ADB截图确认商品动力参数为12V、1:34（实际34.014）、空载300±12%rpm/240mA、额定260±12%rpm/1.1A/1.5kgf·cm、堵转6.2A/8.7kgf·cm、96g、PH2.0六线接口；霍尔/GMR两种版本均列在参数表中，实际选购版本尚未确定。以上是商品标注，未独立实测。本文件为规划，未修改控制代码、未烧录、未完成实物验证。

**适配结论：电压和逻辑接口可匹配，但两块普通TB6612的持续爬坡电流余量不足，不能称为已匹配的2kg爬坡动力系统。** TB6612的每路1.2A是平均输出绝对最大额定值，3.2A只允许10ms单次脉冲，普通小模块的连续能力还受双通道散热影响；MG370额定1.1A接近该上限，堵转6.2A远超峰值。若长期接近额定负载，优先重新选散热合格、带硬件限流的驱动，例如DRV8874；不能依赖渐变PWM或速度PID替代电流限制。以下两TB接线用于用户所选方案的接口规划和受控验证，未承诺满载能力。

本文按原始引脚全部引出的普通 TB6612FNG 模块编写。按端子名称接线，不按图片位置或不同厂家的排针顺序接线。普通双路模块与 D24A 四路稳压整合板不是同一接法。

## 1. 当前代码核对与适用范围

核对了 hardware/Src/pwm.c、motor.c、ps2.c 及当前版本说明。

- 电机编号1～4依次为左后、右后、左前、右前；当前麦轮混控按这一顺序。
- TIM2 的 PA0/PA1、PA2/PA3 和 TIM3 的 PA6/PA7、PB0/PB1，是四组双输入 PWM，正常时仅一侧输出 PWM。
- 当前20kHz是72MHz定时器时钟下的值。当前代码不使用独立 PWMA/PWMB。
- 手柄 DAT=PB14、CMD=PB15、CS=PB12、CLK=PB13。
- 当前程序没有编码器测速、速度PID、舵机输出，也没有 PB5 驱动使能控制。
- 当前后轮极性-1、前轮+1来自旧TT实测。换MG370后必须重新确认，不能把旧补偿作为新电机的安装事实。
- 换胶轮后必须将麦轮混控改为左右差速；胶轮无法执行原来的横移。

TB6612的PWMA/PWMB保持高电平时，IN1/IN2的00为高阻停止，10/01为两个方向，11为短路制动。因此从真值表看可以沿用当前双输入PWM输出方式。真实电流、波形、起步和制动需要换板实测，不能称为已验收。

## 2. 电源接线

本次截图所示电机是12V版。用户确认主方案是两节18650串联，经升压模块调到12V，再给驱动板VM供电；VMOTOR在此主方案中即升压输出12V。额定12V不代表一块普通XL6009可以承担四轮负载，具体升压模块尚未确认满足要求。

```text
两串电池正极 → 主开关 → 电源分配
                    ├─ 升压模块输入 → 输出12V → 两块 TB6612 的 VM
                    ├─ 逻辑降压5V → 核心板确认的5V输入、PS2转接板5V输入
                    └─ 舵机降压/BEC → 将来舵机动力电源

电池负极 → 公共GND → 电源模块、两块驱动、STM32、PS2、编码器、舵机
核心板3V3 → 两块TB6612的VCC、PWMA、PWMB
```

| 对端 | 接到哪里 | 说明 |
|---|---|---|
| TB6612① VM | VMOTOR正极 | 给左后、右后电机动力 |
| TB6612② VM | 同一VMOTOR正极 | 给左前、右前电机动力 |
| 两板 VCC | STM32核心板3V3 | 逻辑供电；本方案不使用5V逻辑供电 |
| 两板 GND | 公共地，动力回流直接到电源分配处 | 避免马达回流经过核心板细地线 |
| STM32核心板5V输入 | 稳压5V | 只接确认有板载稳压的5V入口，不接3V3脚 |
| PS2转接板VCC | 稳压5V | 以现有带3.3V稳压转接板为前提；不是裸接收器VDD |

电源分支不是多个稳压器输出正极并联。逻辑与舵机采用独立分支布线；多只舵机的电源能力根据实际型号和同时动作情况再定。电机/舵机电流不经过STM32板、PS2板或面包板电源条。

升压模块IN+接开关后的两串电池正极，IN-接电池负极；OUT+调好12V后接两板VM，OUT-接公共地（以普通非隔离模块为前提）。主控/PS2的5V降压仍从电池处分支；两板VCC和PWMA/PWMB仍是3.3V，不能接升压12V。TB6612芯片的VM工作上限13.5V不是15V，整板电容额定值、升压纹波和制动母线过冲也需核实。

三串锂电直供VM是备选，不是用户当前选定主方案。若以后采用，需确认电机和整板允许满电12.6V。若两串7.4V不升压直接给本次12V电机供电，只能作为低电压验证，不得使用12V额定转速/扭矩作为7.4V性能保证。

按四只电机同时处于商品额定点预算：12V×1.1A×4=52.8W；两串7.4V、升压效率暂按85%时，输入约8.39A，四轮起步峰值还未计入。三串标称11.1V、四轮均取1.1A的电流预算约4.4A，实际电流随电压和负载变化，电池、保护板、开关、端子和线材都需据实际起步电流核实。这不是说平地轻载始终消耗52.8W。

一块普通XL6009升压小板暂不作为四轮动力支路。若要使用，必须先取得实际负载、升压比、连续输出功率、动态掉压和温升数据。数显不代表能够承担电机起步电流。普通纯升压拓扑不能把两串电池降至5V/6V。

## 3. 四电机动力与控制

驱动①放后轴，驱动②放前轴，便于与当前代码编号对应。

| 电机编号/轮位 | 对应驱动通道 | 两根电机动力线 | IN1 | IN2 |
|---|---|---|---|---|
| M1 左后 | ①A | M+→AO1；M-→AO2 | ①AIN1→PA0 | ①AIN2→PA1 |
| M2 右后 | ①B | M+→BO1；M-→BO2 | ①BIN1→PA2 | ①BIN2→PA3 |
| M3 左前 | ②A | M+→AO1；M-→AO2 | ②AIN1→PA6 | ②AIN2→PA7 |
| M4 右前 | ②B | M+→BO1；M-→BO2 | ②BIN1→PB0 | ②BIN2→PB1 |

M+/M-是电机接口名称，不能预测安装后的车轮前进方向。架空单轮测试后，统一调整软件极性，并让编码器计数的正方向与机械前进一致。

两块板的PWMA、PWMB共四个端子都接3V3，保持使能。这是专门为沿用当前双输入PWM而选的接法；速度由AIN/BIN上的PWM控制，不是直接将3V3供给马达，也不是把IN1/IN2固定高。

推荐后续软件使能线：PB5→两板STBY，PB5与GND之间加10kΩ下拉（须确认小板没有冲突的固定上拉）。初始化/异常时PB5低；PWM完成初始化且满足控制使能条件后才置高。STBY是逻辑使能，不是电源输出。

当前固件未实现PB5使能，所以按推荐STBY接PB5后，当前固件不会正常启用驱动。只有需要单独验证旧PWM时，才可在VM断电下将两板STBY暂接3V3；此时失去独立GPIO关断，不视为最终方案。禁止把STBY同时硬接3V3和PB5。

## 4. 编码器接口：当前F103的普通霍尔规划

本文以下表格仅按支持3.3V供电/输出的低线数AB霍尔编码器规划；MG370具体版本尚未确认。六线插头顺序必须看电机厂家图，不能按颜色或其他型号插头顺序猜。

| 电机六线功能 | 接到哪里 |
|---|---|
| M+、M- | 该轮对应驱动的两输出端 |
| 编码器VCC | 经厂家确认允许的3.3V；核对核心板3V3负载预算 |
| 编码器GND | 公共GND |
| 编码器A、B | 下表STM32输入 |

若只能5V供电，要确认A/B是推挽还是开集电极/开漏、板上上拉到哪里，随后选电平接口。不能把5V推挽输出直接套用这份3.3V方案。开集电极且无适当上拉时，按厂家要求设置到3.3V的上拉。

| 轮位 | A相信号 | B相信号 | A相计数中断 |
|---|---|---|---|
| M1 左后 | PB3 | PB4 | EXTI3 |
| M2 右后 | PA11 | PA12 | EXTI11 |
| M3 左前 | PB8 | PB9 | EXTI8 |
| M4 右前 | PB10 | PB11 | EXTI10 |

此方案只让四个A相触发中断，在中断中读取A/B确定方向；不是八根线全部配置中断，也不是四路硬件定时器编码器模式。A相双边沿是2倍计数，测速换算须确认厂家线数的定义、所在轴和减速比。EXTI8/10/11会共享中断处理入口，软件要逐项处理挂起位。

PB3/PB4复位属于JTAG相关引脚：软件必须关闭JTAG并保留SWD，CubeMX对应SYS Debug=Serial Wire。PA13/PA14保留ST-Link。当前源码虽然有JTAG_Set辅助函数，但主入口未启用这项编码器配置，不能只接线就得到测速。

PA11/PA12这样分配后，不使用USB数据功能；若板上USB上拉电阻已接PA12，应按核心板原理图确认是否需要断开，避免影响编码器B相。USB供电与外部5V也不得未经确认并接。本方案常态用外部5V和SWD下载。

本表保留PA4/PA5供后续ADC电压/电流采样，PA9/PA10供串口，PB6/PB7供I2C扩展。引脚没有重复分配，但实际GPIO中断处理能力必须按MG370最高脉冲率验证。

若最终选500线等高分辨率GMR，不直接使用本软件中断规划。应核算输出脉冲定义和最高边沿频率，再优先考虑资源更充分的主控或外部硬件计数；F407方案需单独分配PWM和编码器定时器。

## 5. 手柄、ST-Link与扩展

| 设备接口 | STM32/电源 |
|---|---|
| PS2 DAT | PB14，输入 |
| PS2 CMD | PB15，输出 |
| PS2 CS/SEL/ATT | PB12，输出 |
| PS2 CLK | PB13，输出 |
| PS2转接板VCC/GND | 稳压5V/公共地，按现有板的输入丝印 |
| ST-Link SWDIO | PA13 |
| ST-Link SWCLK | PA14 |
| ST-Link GND | 公共地 |
| ST-Link NRST（可选） | 核心板NRST |

外部供电时不要默认将ST-Link 3.3V输出再并到核心板3V3；探针的目标电压参考与电源输出按实际型号区分。

多舵机可通过PCA9685规划：SCL→PB6，SDA→PB7，模块逻辑VCC→3V3，GND→公共地，V+→独立舵机电源。舵机S接对应通道信号端，V接舵机电源、G接地，不能靠核心板供电。具体模块端子与电流承载需看实物。

这一I2C扩展方案替代旧PB6/PB7直接接两舵机的建议，不能两种用途同时使用。可在相同总线上接地址不同、逻辑电平兼容的I2C传感器。PA9/PA10留作UART1，PA4/PA5可接适当分压/采样电路，绝不直连电池。

## 6. 后续代码和首次验证

需要增加PB5使能与初始化顺序、霍尔计数/测速、速度PID、故障与计数超时处理。当前旧固件只提供开环PWM，没有加入这些功能。普通模块也不能因写了PID就获得硬件电流限制。

换胶轮时先改左右差速目标：左侧两轮同目标，右侧两轮同目标；右杆给转向，横移要求须取消/重定义。保留麦轮时才继续使用麦轮混控。

1. VM断开，单独调好逻辑电源；万用表确认5V、3V3以及共地。
2. 核对驱动VCC、VM、STBY、PWMA/PWMB；不要将电机电源接进逻辑脚。
3. 编码器供电和接口确认后，手转每只轮子，先验证脉冲、计数和方向。
4. 新固件完成后，架空接入单只电机，低输出确认编号、方向和测速，再逐个接四轮。
5. 对MG370重新确认机械前进方向，修改旧TT极性；换胶轮要先改混控。
6. 同时起步时测VM、逻辑5V及温升，再逐渐增加负载；不要用商家适配列表替代爬坡验证。
7. 首次换电机建议先不启用旧弱反转急停。当前代码按PWM施加反向脉冲，未测转速和电流；新电机负载和制动电流不同，需要重新验证。调试暂停/下载前断开两块VM正极。
