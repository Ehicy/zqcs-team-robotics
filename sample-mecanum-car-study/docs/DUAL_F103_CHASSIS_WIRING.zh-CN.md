## 1. 合理性与动力瓶颈

**13PPR 霍尔的双板控制资源可以安排；用户截图中的小升压板及 TB6612 小板不能直接认定为四 MG370 额定负载爬坡的合格动力选件。**

用户电机截图：12V，减速比实际34.014，空载300rpm/240mA，额定260rpm/1.1A/1.5kgf·cm，堵转6.2A/8.7kgf·cm，96g，PH2.0六针；商品注明不能堵转。这是商品标称值，尚未实测。

- 图中升压板测试为7.4V输入、12V输出1.5A；四机额定工作点合计 **4.4A/52.8W**。即使每两个电机各用一块同款升压，1.5A仍小于每组额定2.2A。普通升压输出不能直接并联增流。
- 后续新候选图片写最大30W、输入9A(MAX)，芯片未确认。按30W预算，单板12V最多2.5A，仍不足四机52.8W；两块分别独立供两个驱动VM，每组额定26.4W只比30W低3.6W，而且MAX不保证持续输出、低电压与起步能力，尚不能认定通过。输入9A不等于12V输出9A，效率92%是标称最高值，不用于保证任意工况。[TI输入限流与输出关系说明](https://www.ti.com/document-viewer/lit/html/SLVAFC4)。新图升压保持“选型待核”，未替用户决定采购。
- 假设7.4V输入、85%效率，该额定工作点的电池输入约8.39A，未计外围与起步；此值不是日常实测耗电。电芯、电池盒及连接线的持续能力和压降仍需确认。
- TB6612官方绝对最大平均电流每路1.2A；3.2A是10ms单脉冲。Operating Range中无PWM时输出上限1.0A（VM≥4.5V）。MG370额定1.1A、堵转6.2A，两路各1.1A时按典型0.5Ω估算芯片导通损耗约1.21W，小板电流和散热余量不足。商品适配列表不等于满载验收，芯片热保护不等于可调限流。

因此保留用户2S升压路线及控制分工；升压需另选满足两串电池整个工作范围的持续输出和起步能力的模块，驱动需升级或受控验证，并核实限流/散热。图仍按所选 TB6612 的接口展示，红字标出瓶颈。

## 2. 两块板的分工与通信

- **A主控板**：读取PS2，计算四轮目标速度并经串口发送；后续舵机、传感器主要接A。A不直接驱动电机。
- **B底盘板**：读取全部四编码器，执行四轮速度PID，控制两驱动板全部四通道；向A回传轮速、状态。
- 两板 USART2：A.PA2/TX→B.PA3/RX；A.PA3/RX←B.PA2/TX；GND共地。3.3V信号，TX与RX交叉，不接RS232电平。
- 指令建议10–20ms更新，带校验和序号。A发现PS2无效/失联/超时，向B发送零速；B超过100ms没有收到有效串口指令则独立停止四轮。上电均默认零速，初始化后才使能驱动；该超时为设计初值，需实测。

## 3. B底盘板逐引脚表

编号沿用仓库已确认轮位：M1左后、M2右后、M3左前、M4右前。TB6612①为后轴，A通道M1、B通道M2；TB6612②为前轴，A通道M3、B通道M4。

| B底盘引脚 | 接线对象 | 用途 |
|---|---|---|
| PA0 / PA1 | M1编码器A / B | TIM2_CH1/CH2硬件编码器，4倍计数 |
| PA6 / PA7 | M2编码器A / B | TIM3_CH1/CH2硬件编码器，4倍计数 |
| PA8 / PA9 | M3编码器A / B | TIM1_CH1/CH2硬件编码器，4倍计数 |
| PB10 / PB11 | M4编码器A / B | EXTI10监听A双边沿，读取A/B判向，2倍计数 |
| PB6 | 驱动①PWMA | TIM4_CH1，M1速度 |
| PB7 | 驱动①PWMB | TIM4_CH2，M2速度 |
| PB8 | 驱动②PWMA | TIM4_CH3，M3速度 |
| PB9 | 驱动②PWMB | TIM4_CH4，M4速度 |
| PB0 / PB1 | 驱动①AIN1 / AIN2 | M1方向GPIO |
| PB3 / PB4 | 驱动①BIN1 / BIN2 | M2方向GPIO；须释放JTAG |
| PB5 / PB12 | 驱动②AIN1 / AIN2 | M3方向GPIO |
| PB13 / PB14 | 驱动②BIN1 / BIN2 | M4方向GPIO |
| PB15 | 两驱动板STBY | 两板共同使能；默认低 |
| PA2 / PA3 | A.PA3 / A.PA2 | USART2 TX/RX交叉 |
| PA13 / PA14 | ST-Link SWDIO / SWCLK | 保留SWD下载调试 |
| PA4 / PA5 | 暂不连接 | 预留ADC采样 |
| 3V3 | 两驱动VCC | 逻辑供电 |
| GND | 公共地 | 电源/信号参考 |

**PB3/PB4默认是JTAG脚，必须关闭JTAG但保留SWD**（CubeMX中SYS Debug选Serial Wire，或配置相应AFIO SWJ重映射）。不要关闭SWD。TIM1/TIM2/TIM3均使用表中默认映射；TIM4四通道统一电机PWM周期，不能同时承担50Hz舵机。

STBY可加10kΩ下拉到GND使复位时默认禁用；需先核实模块有没有固定上拉/硬接高电平。不能同时将STBY硬接3.3V和GPIO。

驱动①AO1/AO2接M1两根动力线，BO1/BO2接M2；驱动②AO1/AO2接M3，BO1/BO2接M4。编码器六针中的M+/M−与VCC/GND/A/B用途不同，不能混接。厂家线序、颜色、插头朝向需按具体版本确认。更换电机后架空重新验证电机和编码器方向，旧TT的后轮反相不能盲目继承。

## 4. A主控板接口

| A主控引脚 | 接线对象 |
|---|---|
| PB14 | PS2 DAT |
| PB15 | PS2 CMD |
| PB12 | PS2 CS/ATT |
| PB13 | PS2 CLK |
| PA2 / PA3 | B.PA3 / B.PA2，USART2交叉 |
| PB6 / PB7 / PB8 / PB9 | 可选四舵机S信号，TIM4_CH1/2/3/4，统一50Hz |
| PB10 / PB11 | 预留I2C2 SCL/SDA，后续传感器 |
| PA13 / PA14 | 保留ST-Link SWDIO/SWCLK |
| 5V / GND | 独立5V控制电源/公共地 |

A与B是两块独立板，A.PB12–PB15接PS2，不与B同名GPIO接驱动发生冲突。主控A的TIM4可选直接产生四舵机PWM，底盘B的TIM4则是电机PWM，两块板的定时器互不影响。选择四舵机PB6–PB9后不能再把A.PB6/PB7用于I2C1；本版传感器预留改用I2C2 PB10/PB11。舵机用符合实际型号和负载的独立5V或允许的5–6V支路，不让多舵机电流流经核心板供电排针；四舵机仅预留，型号及电源能力未确定。

## 5. 电源接法

```text
两串18650正极 → 保险丝／主开关 → 分支
                                 ├ 升压IN+ → 调好12V的OUT+ → 两驱动VM
                                 └ 5V降压IN+ → OUT+ → A/B核心板5V输入、PS2转接板VCC
电池负极 → 两DC-DC的IN−与公共GND
DC-DC的OUT−、A/B GND、两驱动GND、PS2 GND、四编码器GND → 公共GND
B.3V3 → 两TB6612 VCC
```

上述适用于普通非隔离DC-DC。**两块核心板的3V3稳压输出不要互接；12V只接VM，不接STM32、TB的VCC或编码器。** 动力正/负线直接从分电端接驱动板，不能经面包板或核心板串接动力电流。编码器VCC可接B.3V3的前提是该版本允许3.3V供电且稳压器电流余量足够；若要求5V，须确认A/B输出电平及内部上拉并配合电平转换。

TB6612官方VM工作范围2.5–13.5V，15V为绝对最大值；设置12V还要验证输出误差与制动回灌。新电机先不直接继承旧弱反转急停，先验证电流、制动效果及母线电压。

**四节2S2P是用户后续询问的备选，尚未替代原两节方案。** 2S2P仍为标称7.4V/满电8.4V，容量与电流分担可增加，仍须升压到12V，并不能解决1.5A升压板和TB电流瓶颈。按上述8.39A输入预算，理想均流时每节约4.20A；输入降到6V且保持该额定功率、85%效率时，总输入约10.35A、理想每节约5.18A。均非日常实测功耗，未计起步与外围。实际分流和电芯持续放电能力需核实。结构应为两个匹配电芯并联组再串联，并配合合适2S保护/均衡，分别监测串联组；仅把两个已有串联电池盒的总正负端并在一起，不能保证单体保护和中点均衡。[TI电池管理指南](https://e2echina.ti.com/cfs-file/__key/telligent-evolution-components-attachments/00-24-01-00-00-02-07-04/Battery-Management-Solution-Guide-2012-_2D00_-slyt420.pdf)、[Panasonic电池使用建议](https://jpn.faq.panasonic.com/app/answers/detail/a_id/18107/)支持串联组监测与匹配条件的要求。

## 6. 编码器测速与旧固件适配

按13PPR是减速前电机轴单相周期数、实际减速比34.014、轮端300rpm计算：前三个硬件编码器4倍计数约 **8,843计数/秒**，第四个A双边沿2倍计数约 **4,422中断/秒**。第四个中断频率是可行实现方向，仍要实测最大速度下的漏计数和PID周期。

**每轮必须用各自的counts_per_rev换算轮速：前三轮约1768.728计数/轮圈，第四轮约884.364计数/轮圈，不能统一采用4倍计数常数。** 厂家PPR定义和减速比实值仍需确认。硬件16位计数处理回绕，采样真实增量须在有符号差值可判别范围内。

当前仓库 `hardware/Src/pwm.c` 把TIM2/TIM3用于八路IN1/IN2 PWM，未实现编码器/PID/双板串口。新固件必须分别构建主控与底盘，把底盘资源改为本文3硬件编码器＋1中断计数、TIM4四PWM、方向GPIO及PB15使能。

**TB标准PWM脚控速时，PWM低会进入短路制动；旧双输入PWM的00停车则是滑行。** 必须按TB官方真值表重新定义运行、滑行、短路制动及STBY禁用，不能直接照搬旧 `pwm_stop_all`、`pwm_brake_all` 或无测速的反转停车程序。

现有60mm麦轮/TT联轴器不保证适配MG370轴，需核对轴径、联轴器及安装孔。换胶轮后应改差速混控，不能沿用麦轮横移公式。
