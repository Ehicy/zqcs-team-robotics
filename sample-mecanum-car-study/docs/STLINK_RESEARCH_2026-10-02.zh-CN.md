## 已取得的证据

| 检查项 | 读回结果与含义 |
|---|---|
| 目标 | Cortex-M3、中容量 STM32F1，Device ID `0x410`，目标电压约3.25～3.26V |
| 固件身份 | Flash 前7260字节与 `backups/motor-openloop-20261002-01/crtc-motor.bin` 一致 |
| 系统时钟 | RAM `SystemCoreClock=72000000`，RCC 配置与 HSE/PLL 72MHz 一致 |
| 主循环 | 两次 HOTPLUG 快照之间 DWT 毫秒增加66293，循环增加5228，平均约12.68ms/轮；没有看到停滞 |
| PWM | TIM2/TIM3 `CR1=1, PSC=0, ARR=3599`，按该时钟配置为20kHz；采样时八路CCR全部0 |
| 手柄 | 未开机／未配对期间 `control_mode=0, control_ready=0`，软件目标和已施加 PWM 都为0 |
| 参数页 | `0x0800F800～0x0800FFFF` 全为FF，尚无新校准记录 |

原固件的加速率200个百分点/秒，满幅从零到100%约0.5秒；换向前等待80ms。程序周期约12.7ms，因此当前证据更支持斜坡造成一部分“黏糊”，不能据此排除电机起转、供电、轮组阻力或无线延迟。

新试验源码把加速率调到500个百分点/秒、减速1000、换向等待40ms，并加入人工辅助横移学习与Flash保存；通过主机测试和Arm GNU编译。以下新增记录为之后完成的下载，见 [最新试验版操作](DRIVER_CALIBRATION.zh-CN.md)。

诊断初期手柄闪烁、接收器常亮，没有有效帧。[配套使用手册第4页](<D:/BaiduNetdiskDownload/手柄控制/塔克创新 l PS2无线手柄使用指导手册V1.0.3.pdf>) 将手柄频闪解释为等待配对；[锁定款说明](<D:/BaiduNetdiskDownload/手柄控制/塔克创新 l PS2手柄锁定款一键锁定使用说明V1.0.0.pdf>) 要求接收器隐藏按键锁定绑定。用户随后说明电源上电后可成功配对，非暂停热连接连续读到有效73帧、使能1、轴127/128。先前整机断电时无帧不能当作程序故障；没有测量接收器电压，不能据此确定具体欠压位置。实时RAM读取可能跨越帧更新，单次大块快照不保证一致；连续短帧另有文件记录。
