# 上层车：行驶、横移与控制迭代

截至 2026-10-16，上层继续使用四个 TT、麦克纳姆轮、STM32F103、两块 DRV8833 和 PS2。任务是把黄块推落交给下层收集，不使用夹爪。本轮未对上层进行新的机械或固件改进。以下日期来自已有修改记录和 Git 检查点，不把历史版本恢复的提交日期当作所有实测动作的准确发生时间。

## 四轮输出与上电准备

**2026-09-15：**以开源小车为学习起点，先跟随 `main → ps2 → motor → pwm` 理清数据流，修复零 PWM 换算、摇杆死区、混合输出超限、无效帧保留输出等问题。上电和异常恢复后，先等摇杆回中、按键全部松开，再接受运动；无效数据不产生伪按键事件。

这样安排是为了把“读到数据”和“允许运动”分开。格式正确只表示本次包符合约定，不能证明无线手柄仍在线；这一限制至今仍需真实失联场景验证。

**2026-09-16：**形成执行顺序学习笔记，理解结构体、指针、按键位和定时器。笔记当时按 L298N 和 50Hz 旧接口讲解，是学习阶段资料，不作为现行接线。

**2026-09-24：**改为两块 DRV8833 双输入控制，PWM 使用 TIM2/TIM3、20kHz。驱动板变更涉及真值表、复用脚及 PWM 输出，不能只换模块仍沿用 L298N 的独立 EN 接法。

当前实现入口：[主循环](../sample-mecanum-car-study/hardware/Src/main.c)、[PS2](../sample-mecanum-car-study/hardware/Src/ps2.c)、[电机](../sample-mecanum-car-study/hardware/Src/motor.c)、[PWM](../sample-mecanum-car-study/hardware/Src/pwm.c)。

## 麦轮横移与四轮补偿

**截至 2026-10-02 的迭代：**逐轮确认轮位为 M1 左后、M2 右后、M3 左前、M4 右前，并处理后轮电气方向补偿、俯视 O 形轮组及四轮统一限幅。开环版本已能前后运动，但横移走弧线；前 85/后 100 的试验补偿曾使偏移加重，因此保留为失败对照，没有把“改了参数”写成“改进已验收”。

随后改为前 100/后 95 默认值，增加 SELECT 人工辅助学习和停车后 Flash 保存。Flash 记录升级到版本 2，避免把旧版本参数当作新默认配置自动加载。没有编码器时，这是对开环差异的人工补偿，不是轮速 PID。

四个检查点都能追溯至独立源码和保留的 [发布 HEX](../sample-mecanum-car-study/releases/firmware/)：

| 检查点 | BIN 大小 | 行为与结果 |
|---|---:|---|
| `chassis/openloop-20261002` | 7260 字节 | 0.5s 线性起步；前后正常，横移有偏转 |
| `chassis/learn85-100-v1-20261002` | 9820 字节 | 前85/后100，版本1校准；队员反馈横移偏移加重 |
| `chassis/pad100-95-v2-20261002` | 10036 字节 | 前100/后95、摇杆曲线、版本2参数；作为后续回退点 |
| `chassis/scurve-stop-20261002` | 11220 字节 | 五次 S 曲线起步与有限停车制动；写入和独立读回通过，停车效果仍需实测 |

**2026-10-16 核对：**队员确认原上层麦轮车可以行驶、横移通过 150mm 桥面；暂不更换底盘，下一轮重点为速度与稳定性。该确认没有给出负载、次数及完整测量记录，不据此宣称所有配置均能可靠过桥。

## 连续遥控、柔和起步与停车

**2026-10-02：**左杆控制平移方向和幅度，右杆控制转向，采用左杆 25%/右杆 50% 三次混合映射；L1/R1 不再作为速度档。目的在于保留全幅输出，同时给小幅对位更多操作空间。

满幅起步采用 `S(x)=10x³−15x⁴+6x⁵`，名义 0.5s 完成；四轮共用比例，避免各轮独立截断改变行驶意图。模拟模式松杆和 START 使用短暂撤驱动、有限弱反转及短路制动；数字/无效帧直接撤输出，不补反转。

这些是开环策略。低占空比不代表低电流，主循环停止时也没有独立硬件定时器保证撤销最后的输出。完成的软件测试与读回不能代替实际停车距离、冲击、电流及温升验证。

**2026-10-16 上传前复验：**上层主机测试全部通过，覆盖 PS2、四轮输出、摇杆边界、起停时序、时钟回绕、校准保存与恢复。测试使用 `SANITIZE=0`，未宣称 UBSan 通过。完整范围见 [验证记录](04-validation.md)。
