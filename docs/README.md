正式队名：**最强初生**。仓库采用完整拼音命名：[Seroliya/zuiqiangchusheng](https://github.com/Seroliya/zuiqiangchusheng)，本目录发布在默认分支 `main`。

更新至 2026-10-17。规则依据为仓库中的 [参赛手册 V1.5](../2026CRTC参赛手册V1.5.pdf)，文档及仓库要求见第 10 页。这里记录真实的学习、方案取舍、实现、失败与验证；计划中的功能单独标出。

最新实板问题与修复：[lower-motor 看门狗启动、故障诊断与复测](11-lower-watchdog-fix.md)。已验证固件写入、通信和诊断；[电机首测](06-lower-motor.md) 已完成逐轮架空试转，四轮同时测试触发编码器异常，闭环仍待验收。

## 上层车行驶与横移过桥

从 [上层车功能开发历程](01-upper-car.md) 阅读：2026-09-15 源码修订，09-24 驱动适配，10-02 遥控与起停迭代，至 10-16 核对上层原车能行驶、横移通过 150mm 桥面。桥面通行由队员确认；最新整车模型、尺寸及负载证据尚待补齐。

## 下层车双板通信与供电

从 [下层车功能开发历程](02-lower-car.md) 阅读：由旧方案转为 STM32＋ESP32，10-13 完成 UART 和灯控验证，10-15 整理 12V/5V 供电，10-16 核对机械装配与后续安排。具体接线及协议见 [整车接线与通信说明](lower-car-wiring.md)。

下层车为四个 MG370、胶轮、两块 TB6612、STM32F103C8 和 ESP32-S3-N16R8。已烧录的 `board-link` 基线通过读回及灯控验证，电机输出仍禁用；不能把灯控成功写成整车可遥控行驶。

## 下层车电机、手机遥控与四目标半自动方案

[电机与编码器说明](06-lower-motor.md) 记录独立 `lower-motor` 后端、四轮原始编码器采样及 ESP32 USB 台架命令；[速度闭环与手机遥控](08-speed-remote.md) 记录四轮 PI、ESP32 BLE 与 [Android 静态面板](../firmware/web/README.md)。源码已实现，手机限速 300mm/s，PWM 上限 25%，逐轮校准默认未确认。本轮新固件与网页尚未烧录、实板测试或发布，构建和主机测试结果单独记录，不能沿用旧灯控验收。

[四目标半自动方案](07-semi-auto-plan.md) 规定红蓝方选择、小路网选路、停车转向与直行、人工末端调整及对齐确认。导航、里程计和舵机动作尚未实现；已实现的轮速闭环与 BLE 先完成台架校准和实物验收。

## 功能验证与中期材料准备

[验证与证据索引](04-validation.md) 分别标出源码、构建、写入读回、队员观察和待验证项目；小体积原始通信记录放在 [evidence/](evidence/)。原始 Flash 和完整本地备份不进入仓库。

参赛正文均在根目录 `docs/`，按具体功能使用 H2 标题，功能内按有证据的日期从早到晚组织。根目录 README 是入口，PROJECT 是工程维护记忆，源码目录的说明保留工程导航用途。

清理前的原始项目记录保留在 [PROJECT.before.md](../PROJECT.before.md)，仅供查看历史讨论与方案迭代；其中过时接线、进度和已清理的本地备份路径不代表当前状态。

提交前还需团队完成以下事项，当前上传不等于已经邮件提交中期材料：

- 上传最新机械模型，补充实测外廓、重量、机构运动、成本/借用件清单及对应证据。
- 对照 V1.5 第 9 页逐项确认拟申报功能；电机、编码器、PI 和 BLE 源码仍需实物验收，不将源码或主机仿真记为实际行驶完成；里程计和路径自动化仍未实现。
- 确认中期底盘指标对手机 BLE 替代 PS2 的认定；目前上层仍使用 PS2，下层 BLE 尚未烧录实测。
- 拍摄需要的视频：MP4、至少 1080p/30fps，按手册第 11 页打包并提交；此前 720×1280 的行驶视频不满足该视频规格。
- 提交默认分支的仓库链接；规则测评、邮件正文及视频附件由团队另行完成。

本项目上层控制基于 [Serialist/sample-mecanum-car](https://github.com/Serialist/sample-mecanum-car)，基线提交 `1fa85bbdcd6c62f33f871284b642959cea975805`；原工程 [GPLv3 许可证](../sample-mecanum-car-study/LICENSE) 和厂商版权声明保留。下层 STM32 使用同仓的 CMSIS/标准外设库，ESP32 使用 Espressif Arduino 框架及 PlatformIO。完整来源、版本、使用范围与修改边界见 [开源与第三方使用说明](05-open-source.md)。各功能文档末尾也分别说明来源。
