## 当前接法

- 电池正极 → 靠近电池的保险 / 手动总开关 → 分到继电器 **COM、+V**。
- 继电器 **NO** → 只接升压 **IN+**；**−V**接公共地，**NC**留空。
- 升压 **OUT+**空载调到 **12.0V**后分到两块TB6612的 **VM**及降压 **IN+**。
- 降压从升压OUT+取12V，**OUT+**空载调到 **5.0V**后供两主控。主控依赖升压输出，需验证电机启动时12V及5V稳定性。
- 按非隔离升降压模块，各IN−、OUT−、电池负极、主控及驱动GND同网。
  功率回流直接回电池/分电点，不通过主控或细杜邦线。电机M−不是公共地。
- 继电器背面焊点朝你、丝印正立，左→右 **NC / COM / NO / +V / −V**；元件面会镜像。
  +V始终在触点前，不能接自己的NO。蓝色继电器的5V是内部线圈电压，PCB标5–80V，实际规格仍需核验。

沿用当前主分支的轮位M1右前/M2左前/M3右后/M4左后，以及GPIO12/13/14三路舵机信号（14为MG995开门）。
当前遥控输入为BLE，PS2明确为备选。舵机动力另行规划。
恢复样式不会恢复旧图错误的轮位、旧GPIO5/7或旧12V直供说明。
