继电器和升压器怎么接

先断电。继电器背面焊点朝你、丝印正立，左→右：NC / COM / NO / +V / −V。翻面会镜像。

COM、+V：各自接保险/手动总开关后的电池＋；NO：只接升压IN＋；−V：接电池负极/公共地；NC：不接。

升压OUT＋调12.0V后分到两块TB的VM及降压IN＋；降压OUT＋调5.0V接主控5V。非隔离模块各IN−、OUT−均共地。+V不能接NO，否则会把接收器自己断电。

只说明连接拓扑，不代表升压小板、继电器、TB6612已能承受四电机启动电流。接VM前先空载测压。

用法与供电边界

浏览时点模块或连线；编辑时可拖模块、改接口、新建或删除线路。修改自动保存在本浏览器；用“导出方案 JSON”留备份，用“保存当前网页”保存一份可独立打开的修改版。

改图不会修改固件。电机 M−不是公共地，M+也不能直接接电源正极；动力两线成对接 AO1/AO2 或 BO1/BO2。两主控3V3输出不并接。

当前供电：2S电池（满电8.4V）经保险/总开关，分到继电器COM与+V；NO只接升压IN+。升压OUT+为12V，分到两VM及降压IN+；降压OUT+为5V供两主控。所有负极/GND共地。下载/调试先断开VM并核对USB防回灌；舵机动力仍需独立合规供电。

TB6612、降压模块、继电器的实际带载能力和反推电流仍待验证；这张图不代表已通过电气验收。
