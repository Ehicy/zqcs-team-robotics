# 双 STM32 应急遥控：接线、手柄操作与参数保存

2026-10-19：用户报告 ESP32 损坏，优先恢复底盘行驶和三路舵机；暂不使用编码器、PID、BLE、Dashboard、里程计或往复测试。新增两个独立构建目标，旧源码和旧目标保留。**本版已完成主机测试与编译；下方底盘 B 已经 ST-Link 直烧并通过写入校验，上方主控 A 现已 ST-Link 直烧并校验；尚未实车验收。**

本版接线以本文和 [最简接线 HTML](../firmware/web/fallback-wiring.html) 为准。特别是 B 板的电机线已按用户要求改到 **PA 引脚区**，不能接好新线后继续运行旧 `lower-motor` 程序。

## 两块板的职责与接口布局

| 板 | 程序 | 工作 |
|---|---|---|
| A：替代 ESP32 的新 STM32F103C8T6 | `fallback-remote` | 20ms 读取 PS2，手柄状态机、三路舵机轨迹、调参、Flash；通过 UART 发四轮开环目标 |
| B：原底盘 STM32F103C8T6 | `fallback-motor` | 接收目标，四轮 PWM、曲线起步、换向等待、限幅反推停止、看门狗 |

布局建议：接收器 → A 板 → 板间三芯线 → B 板 → 两块 TB6612 → 电机。舵机信号插座集中在 A 板旁；两块驱动靠近底盘电机。电源与电机大电流线沿底盘边缘走，不让电机和舵机回流穿过主控的地线或面包板电源轨。

A 的手柄用 PB12–PB15，三路舵机用 PB6–PB8，串口用 PA2/PA3，互不冲突。B 的 12 根电机 PWM/方向线全部位于 PA；STBY 单独使用 PB15，串口集中在 PB10/PB11。保留两块板的 PA11/PA12 USB 与 PA13/PA14 SWD。保留 USB 引脚不等于新板已经安装 USB loader。

本次照片：上方主控 A 的 USB 朝下，下方底盘 B 的 USB 朝上，两块 TB6612 均在底盘右侧。B 的 PA0–PA7 位于右排，PA8/PA9/PA10/PA15 位于左排；“PA 区”不是同一条物理排针。当前 HTML 已按照片逐排展示全部接口，并保留现有已烧录分配。

## 逐线接线

### A 板：PS2 接收模块

| 接收转接板丝印 | A 板引脚 | 方向/用途 |
|---|---|---|
| CS / SEL / ATT | PB12 | A 输出，选中接收器 |
| CLK | PB13 | A 输出，通信时钟 |
| DAT / DI | PB14 | A 输入，接收手柄数据 |
| CMD / DO | PB15 | A 输出，给接收器发送轮询命令 |
| 新板 VDD | A 板 3V3 | 轮趣附送说明书确认接收器允许3.3–5V，本车采用3.3V |
| GND | A GND / 降压 OUT− | 与 A、B 共地 |

新板右侧小排针按照片从上到下为 ACK、CLK、CS、DO、DI、VDD、GND；ACK不接。左侧九针插座的两个NC不接，不往NC引脚供电。此板DI对应DATA/PB14，DO对应CMD/PB15；不要仅凭其他厂家的DI/DO命名推断方向。已核对用户提供的轮趣说明书第3、5、7页及厂家F4例程，DI/DO方向和ACK不使用均一致；厂家PA0–PA3仅属于其例程，不改变本车PB12–PB15分配。接收器逻辑和供电不同，不能把 12V 接入；换型号时重新确认供电和 DAT 电平。

普通无锁款：装好手柄电池并打开 ON，接收器供电后自动配对；不需要按锁定款的隐藏绑定键。按 MODE/ANALOG 切模拟模式，本固件必须读取到 `0x73` 才接受运动。`0x41` 数字模式、读帧失败都会锁定。睡眠可用 START 唤醒，但 START 本身也是停止键，唤醒后仍需回中、SELECT 解锁。

此前的“RX 常亮、POWER 闪烁”没有在本版实测排除。灯态不能替代读取模式与行驶测试；若无法解锁，先排查接收器供电、配对、MODE、四根信号线和板间链路。

### A 板：三路舵机

| 通道 | 机构/型号 | 信号脚 | 默认允许脉宽 | 启用参考值 |
|---|---|---|---|---|
| 1 | 大臂 DS3128，原记录为 360°位置型 | PB6 / TIM4_CH1 | 1300–1700μs | 1500μs |
| 2 | 小臂 MG995 | PB7 / TIM4_CH2 | 1300–1700μs | 1500μs |
| 3 | 开门 MG995，目标约 90°行程 | PB8 / TIM4_CH3 | 1000–2000μs | 1500μs |

50Hz PWM。每路红线接适合舵机电流的 5V 分电支路，棕/黑线接公共地，黄/橙/白信号线按上表接。不要把三路舵机的供电电流穿过 STM32 的 5V 针脚。

**上电不产生舵机 PWM；读取 Flash 也不自动使能。** 手动启用只会从保存的“参考脉宽”开始输出。程序没有舵机轴角反馈，不知道实际姿态：若机构当前不在参考脉宽对应的位置，首次输出仍可能使舵机突然转动。支撑机构、使参考姿态与实际位置匹配后再启用；限速不能解决未知首次姿态。

已启用后的运动使用 100μs/s 速度、200μs/s² 加速度限制。超出该通道上下限的命令直接拒绝，不自动夹到端点。上下限约束的是命令脉宽，并不能感知实际碰撞、卡死、连杆干涉或过载。MG995 的实际 90°位置需要逐步标定，不能把 1000–2000μs 直接视为已验证的 90°机械行程。

### 两板串口：只需三根线

| 从 | 到 |
|---|---|
| A PA2 / USART2_TX | B PB11 / USART3_RX |
| B PB10 / USART3_TX | A PA3 / USART2_RX |
| A GND | B GND / 公共地 |

115200、8N1、3.3V TTL，不是 RS232；TX 接对方 RX。两块板分别接正常 5V 电源，不靠串口反向供电。两板板载 3V3 稳压输出不相连。

### B 板：TB6612 全部电机信号集中到 PA

| 驱动接口 | TB6612 ① | TB6612 ② |
|---|---|---|
| A 路电机 | M1 右前 | M3 右后 |
| PWMA | PA0 / TIM2_CH1 | PA2 / TIM2_CH3 |
| AIN1 / AIN2 | PA4 / PA5 | PA8 / PA9 |
| B 路电机 | M2 左前 | M4 左后 |
| PWMB | PA1 / TIM2_CH2 | PA3 / TIM2_CH4 |
| BIN1 / BIN2 | PA6 / PA7 | PA10 / PA15 |
| AO1 / AO2 | M1 的两根电机动力线 | M3 的两根电机动力线 |
| BO1 / BO2 | M2 的两根电机动力线 | M4 的两根电机动力线 |
| STBY | 两块均接 **B PB15** | 同左 |
| VCC | B 板 3V3 | B 板 3V3 |
| VM | 升压后 12V | 升压后 12V |
| GND | 公共地 | 公共地 |

STBY 共用网外接 **10kΩ 到 GND**，复位或程序未启动时保持禁用；不能硬接高电平。仅这一根共用使能线留在 PB，因为保留 USB、SWD 后 GPIOA 不够容纳全部 13 根控制信号。PA15 已释放 JTAG，保留 SWD；ST-Link 仍能下载。

普通 TB6612 模块的三个 GND 通常在板内相通，属于同一地。当前图每板选照片可见的左下 GND，用可靠粗线回升压 OUT−，另外两口保留、不重复拉线；主控地线回降压 OUT−。电机电流不要经主控细地线或面包板电源轨回流。模块不确定时，断电用蜂鸣档两两确认导通。VCC 采用 3.3V，避免 VCC=5V 时输入高电平门限与 STM32 的 3.3V 信号不匹配。

保留原电机动力线的已验证顺序时，默认方向为 `[+,-,+,-]`，即 M2、M4 软件反向。改线后必须架空逐轮核对，不能因为沿用默认值就认定车头方向正确。**先断电并拔掉旧编码器的 A/B 信号线及供电线，四根线各自绝缘**；新电机 PA 和 UART PB10/PB11 占用了旧编码器脚，不能让编码器输出与 MCU 新输出相接。旧 TB6612 控制线也要从旧 GPIOB 分配移除。电机两根动力线仍接驱动输出，不能依据未知六针孔序猜线。

### 供电和公共地

```text
2S 电池（满电 8.4V）
  → 保险 / 总开关 / 继电器受控正极
  → 分成两路，并联接输入（不是先升再降）
      ├ 升压器 IN 接7.4V，OUT调12V → 两块 TB6612 VM
      └ 降压器 IN 直接接7.4V，OUT调5V
          ├ A 板 5V、B 板 5V（新 PS2 转接板 VDD 接 A 3V3）
          └ 舵机专用分电支路 → 三路舵机电源

不需要额外“公共GND模块”，负极按实际端子分线：
升压 IN−、降压 IN−、继电器供电负极 → 电池负极
两块驱动各一根可靠 GND → 升压 OUT−
A / B / 接收器 / 舵机负极 → 降压 OUT−
升压及降压各自的 IN− / OUT−：普通非隔离模块内部相通，断电通断档核对
B 板 3V3 → 两块 TB6612 逻辑 VCC
```

VIN 和 VOUT 是输入与输出，不能直接短接。继电器受控触点切正极；若是 COM/NO/NC 结构，常断用 COM→NO，模块供电端按它自身规格另接。不同无线继电器端子不通用，仍需核对实物丝印。

电机、舵机的回流分别回到分电端，主控地线不要串在大电流回路中。外部 5V 与 USB/ST-Link 供电的防回灌未核实，下载时使用单一供电来源。用户已报告电池、驱动和升压带载验证通过，本版未重复验证；这不代表堵转、反推或全部舵机同时动作都已验收。

## 手柄操作速查

打开 [手柄操作演示](../firmware/web/fallback-controller-guide.html)：选择操作后点“上一步 / 下一步”，手柄图会高亮本步骤的按键，并显示持续时间、预期结果；“播放预期灯光”可演示 PC13 灯。页面仅作教学，不连接车辆。原接线页标题下也有独立入口；下方完整指南包含全部按键与 13 项参数。

组合键建议保持摇杆回中；解锁与长按组合会检查回中。`↑↓←→` 指十字键，`L3` / `R3` 指垂直按下左 / 右摇杆（不是推杆）；各组合之间先松键，再按下一组。长按组合只按表中指定键，额外按键会使计时无效。

| 操作 | 按法 | 结果 |
|---|---|---|
| 手柄按键测试 | 按下左摇杆 L3 | A 板 PC13 用户灯单闪一次；长按不连闪，松开后可再按。无需解锁或 B 板就绪，数字/模拟有效帧均可；PWR 电源灯不能软件控制 |
| 解锁底盘 | 四轴回中至少 0.3 秒，再单按 SELECT | 已有模拟手柄帧且两板连通才解锁；不会自动开车 |
| 前后行驶 | 左摇杆上下 | 开环目标，推得越大 PWM 越大 |
| 左右转向 | 右摇杆左右 | 左右差速；可边走边转、原地旋转 |
| 普通停车 | 两摇杆松回中 | 单次限时反推，结束后禁用驱动；仍保留解锁状态 |
| 停止锁定 | START | 单次限时反推后关驱动，底盘锁定；舵机冻结最后命令 |
| 选择舵机 1/2/3 | 按住 L1，点 □ / △ / ○ | 大臂 / 小臂 / 门；底盘停止并锁定 |
| 启用选中舵机 | L1＋R1＋↑ 持续 1 秒 | 在当前设定的参考脉宽开始 PWM，必须先核对姿态 |
| 舵机正/反向微调 | L1＋↑ / ↓ | 每次增加/减少 `jog_us`；持续按住会重复 |
| 停止舵机调节 | 松开 L1，或 START | 冻结当前输出脉宽，保持力矩；不是松力释放 |
| 关闭选中舵机 PWM | L1＋R1＋↓ 持续 1 秒 | 释放该路，可能失去支撑力；先支撑机构 |
| 进入调参 | SELECT＋START 持续 2 秒 | 进入 TUNE，底盘停止并锁定 |
| 调参项目切换 | ← / → | 循环选 1–13 项，LED 显示编号 |
| 参数增减 | ↑ / ↓ | 单次一步，持续按住重复；越界拒绝 |
| 调参时选舵机 | L1＋□ / △ / ○ | 第 7–9 项针对选中舵机；切换不会使舵机动作 |
| 切换单轮方向 | 调参模式 L2＋△ / □ / ○ / × | 分别切换 M1右前 / M2左前 / M3右后 / M4左后 |
| 读取当前参数值 | R3 | PC13 灯报四位十进制数，见下节 |
| 保存 Flash | 调参模式 R1＋SELECT 持续 2 秒 | 需先停止调参至少 1 秒，两板连通，驱动禁用；保存后重新锁定 |
| 退出调参 | 单按 START 或 SELECT | 回到 LOCKED；再回中、单按 SELECT 才能解锁 |
| 恢复内存默认 | 调参模式 L2＋R2＋START 持续 3 秒 | 恢复 RAM、关闭三路舵机 PWM；**不自动写 Flash**，先支撑机构 |

肩键不再承担行驶档位加减，速度上限在调参菜单中修改。胶轮车不能横移，左摇杆左右不输出平移命令；所有四轴回中才满足解锁和长按组合条件。

按住 ↑/↓ 首次立即调整，400ms 后开始每 100ms 重复。释放 L1 后舵机冻结，不继续追赶剩余目标。进入舵机模式后底盘不自动恢复行驶，必须重新解锁。断联、无效帧或通信故障会锁定底盘、冻结已启用的舵机；恢复链路也不会自动续跑。硬件复位后 PWM 关闭，重力机构仍需机械支撑。

## 所有可调参数

LED 菜单编号从 1 开始，代码内部下标从 0 开始。上电选择舵机 1；切换舵机后第 7–9 项随之切换。

| LED 编号 | 参数 | 初始值 | 范围 | 每步 |
|---|---|---|---|---|
| 1 | 最大 PWM 占空比 | 10% | 10–100% | 5% |
| 2 | 转向比例 | 100% | 20–100% | 5% |
| 3 | M1 右前输出系数 | 100% | 50–100% | 1% |
| 4 | M2 左前输出系数 | 100% | 50–100% | 1% |
| 5 | M3 右后输出系数 | 100% | 50–100% | 1% |
| 6 | M4 左后输出系数 | 100% | 50–100% | 1% |
| 7 | 选中舵机最小脉宽 | 大/小臂 1300，门 1000μs | ≥500μs，需保留最小 20μs 窗口 | 10μs |
| 8 | 选中舵机最大脉宽 | 大/小臂 1700，门 2000μs | ≤2500μs，需大于最小值 | 10μs |
| 9 | 选中舵机首次启用参考 | 1500μs | 必须位于该路最小与最大值之间 | 10μs |
| 10 | 舵机每次微调量 | 5μs | 1–20μs | 1μs |
| 11 | 静止起步曲线时间 | 500ms | 100–1500ms | 50ms |
| 12 | 反推最大占空比 | 5% | 0–5% | 1% |
| 13 | 反推最长时间 | 30ms | 0–30ms | 5ms |

调参修改参考值不会让已启用的舵机自动跳到新参考；关闭后再次显式启用才采用。缩小上下限时，若会把当前输出或目标排除在范围外，则整次修改拒绝，不偷偷改变当前位置。所有参数是开环值，不是 PID 系数，也不是实际速度或角度测量。

方向位默认十进制 10（二进制 1010），对应左侧 M2/M4 反向；用表中的 L2 组合逐轮切换，保存时与其余配置一起写入。方向只改 RAM 时，断电会恢复上次保存值。

## 看 PC13 灯读状态和数值

观察的是 **A 板 PC13 用户灯**，不是接收器 RX/POWER 灯；B 板灯不承担本菜单。

| 灯态 | 含义 |
|---|---|
| 每 2 秒短亮一次 | 底盘锁定/未就绪；不能仅靠此区分链路和手柄问题 |
| 常亮 | 底盘已解锁 |
| 400ms 亮、400ms 灭 | 舵机操作模式 |
| 一组 N 次短闪、间隔后重复 | 调参项目 N（1–13） |
| 一次 2 闪 | 进入调参提示 |
| 一次 3 闪 | 保存成功/配置未变化，或恢复内存默认成功 |
| 一次 5 闪 | 越界、拒绝、保存条件不满足或写入失败 |

R3 报数会暂时覆盖菜单灯：先长亮 1 秒，再暗 0.6 秒，然后报 **四位数，保留前导零**。每位之间暗 0.8 秒；1–9 为相应次数的短闪，数字 0 为一次 0.6 秒长亮。

例如起步时间 500ms 报 `0500`：长亮起始标志 → 0（长）→ 5（短闪五次）→ 0（长）→ 0（长）。最大 PWM 10% 报 `0010`；参考 1500μs 报 `1500`。完成后恢复菜单编号闪灯。一次读数可能持续十余秒，期间别把报数误认成保存回执。

## 推荐调试次序

1. **确认两板安装状态**：A 主控和 B 底盘均已 ST-Link 直烧并校验；底盘已按用户要求换接并再次重烧通过。下载前电机 VM 和舵机正极断开，两个目标均从 0x08000000 启动，本方案不用 USB bootloader。
2. **只测试手柄和串口**：两板供电、共地，打开手柄，切模拟模式；四轴回中后 SELECT，A 灯应常亮，START 回到短闪。不能解锁时不要用大油门“试出来”。
3. **架空核对方向**：保持默认 10%，短推前进。M1/M3 在右、M2/M4 在左，轮胎顶部应都朝车头。某轮反了，在调参模式用 L2＋对应面键切方向；松键、退出、重新解锁后短测。不要带电拔换电机线。
4. **落地调直行**：从低占空比开始，小范围前进/后退。先确认无机械卡滞、轮胎差异和供电问题，再降低较快一侧的两个系数。开环不能自动补偿不同负载，前后或不同地面不一定都直。
5. **调启动和停车**：第 11 项减小会更快起步，先逐步减少；12/13 项先从较小值测试，若停后反向窜动就减小或设为 0。松杆和 START 都要测；确认断手柄/断串口时直接关输出且不反推。
6. **逐路标定舵机**：支撑机械臂、选通道，核准参考姿态后手动启用，用小步进找可用窗口。接近机械限位就停止，先缩小软件窗口，再考虑扩大；不要用 500/2500μs 极限去寻找硬限位。门舵机同样按实际机构标定约 90°。
7. **最后保存**：把车停稳并支撑机构，进入调参，松开调参键至少 1 秒，再按 R1＋SELECT 2 秒；等成功 3 闪，重新握手锁定。断电再上电应恢复参数，但舵机仍不自动启用、底盘仍需 SELECT。

保存只看 B 板新鲜状态显示驱动禁用，没有编码器就不能证明车身已经物理静止。舵机必须没有待执行轨迹，但保存会保留已启用的保持 PWM；重启仍会关闭。

## 曲线起步和反转急停的实际含义

静止起步采用五次 S 曲线 `6x⁵−15x⁴+10x³`，默认 0.5 秒，固定目标时两端斜率平缓。摇杆目标在起步中变化不会不断重置计时，目标突变受变化率约束；不能把不断改变目标时也称为完美限加加速度轨迹。已运行后的正常调速每秒最多改变 2000‰ PWM。

直接从前进推到后退：先按每秒 4000‰ 降低 PWM 到零，所有轮归零后等至少 50ms，再按新目标曲线起步。这里判断的是**输出指令归零**，不是测得轮速归零。

松杆、START 或切换舵机/调参导致的操作者停车：立即撤驱动，等待 10ms，再按此前输出比例给予最多 5% PWM、最多 30ms 的反向脉冲，然后禁用 STBY。低于 10% 的先前轮输出不反推；例如先前为 50% 时，默认反推为 2.5%。重复按/长按不会延长窗口，已经错过的窗口不会补执行。任一反推参数为 0 可关闭反推。

手柄读帧无效、输入过期、串口故障、主循环停顿等：**直接撤输出，不反推**。没有编码器或电流反馈，软件不知道真实零速，也不能保证瞬间停车；反推可能不足，也可能让轮子短暂反转。占空比限幅不是限流，堵转保护不能由这组参数替代。

## 状态机、通信与 Flash 设计

主控状态：`LOCKED → DRIVE` 需回中＋SELECT；L1 转 `SERVO` 并锁住底盘；SELECT＋START 转 `TUNE`；START、退出机构操作、断联或故障回 `LOCKED`。各组合键要求连续回中，不累计摇杆偏离前的长按时间。

B 板输出状态：`IDLE → RAMP → RUN`；换向经 `REVERSING → COAST`；操作者停止经 `COAST → BRAKE → IDLE`；故障直接 `IDLE`。三路舵机各有自己的目标、位置指令和速度状态，由同一循环非阻塞推进；没有引入三条阻塞控制线程。

通信沿用旧项目的 COBS/CRC16 编码器，但使用独立消息类型 64–68、新握手标签和会话令牌，旧 PID 程序不会把新消息当作驱动指令。A 每 20ms 发送控制，B 每 50ms 回状态；源输入最长 120ms，收包队列年龄达到 50ms 失效，300ms 无合法对端包重新握手。坏 CRC/旧序号不刷新有效期。缓存输入不能凭重复发送延长寿命。这里的令牌用于区分会话，不是密码学身份认证。

两块板入口共用 `fallback_runtime.c` 的路由/事件处理：无效手柄输入优先发送“不反推停止”；每个解码包及时处理 STOP，不被后面的 CONTROL 覆盖。只有有效期内的明确不反推 STOP 能确认清除底盘看门狗锁存，过期 STOP 或反推 STOP 不清故障；仍需操作者重新解锁。反推过程中发现非法目标或非法刹车参数也立即撤输出。

参数仅保存在 A 板 Flash 最后两页 `0x0800F800–0x0800FFFF`。每条 64 字节、每页 16 条，双页追加日志、CRC、最后写提交标记；换页时保留上一页最后有效记录。配置未变化不实际编程；相邻保存尝试至少间隔 30 秒。保存失败也限制重试，避免按住组合键连续磨损 Flash。无有效记录时用默认值，不自动写入。

Flash 保存后重建串口会话、保持锁定；不自动恢复运动。旧 TT 的标定记录使用不同标记，加载时忽略；新日志轮换可能擦除这些历史页，需恢复旧 TT 参数时先另行备份，不把它们当作永久档案。B 板不写本配置日志。
