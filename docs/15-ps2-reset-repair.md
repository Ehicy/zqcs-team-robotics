# 普通无锁 PS2 手柄：断电重启、重新配对与模式核对

适用：本项目当前的塔克创新普通无锁 PS2 无线手柄、原配接收器、带 3.3V 稳压的直插转接板。整理日期：2026-10-19。本文是资料核对和操作指南，未连接、复位或测试实物。
> 2026-10-19补充：用户更换为背面标 ACK/CLK/CS/DO/DI/VDD/GND 的转接板。本页旧转接板的5V输入说明不适用于新板；用户随后提供轮趣附送说明书，确认接收器允许3.3–5V；本车采用3.3V。新手柄配对依据轮趣资料，见应急指南末节。无线配对结论仅适用于已核对的塔克产品，不据转接板外形认定新接收器版本。


## 先说结论

**可以把手柄与接收器两端完全断电，再重新上电自动配对。厂家这份普通款手册没有提供“清除绑定”“恢复出厂”“全部重置”的按键或命令，不能把断电重启说成已经清除了内部绑定。**

普通无锁款不要套用锁定款隐藏按键的绑定/解绑流程，也不要短接接收器未知焊盘。手柄 MODE、机器人参数恢复和 STM32 复位，都不等于接收器恢复出厂。

## 新拿到的手柄不确定是否锁定款时

**“平时闪烁，按 MODE 变快闪”不能作为普通款/锁定款的识别证据。** 当前两份厂商资料都没有把这个特定灯态定义为版本识别、恢复出厂或清绑定状态。普通款说明只明确了搜索、配对、睡眠与 MODE 切换模式；不能自行把按 MODE 后的快闪解释为某个未公开功能。

厂家《PS2 手柄锁定款配对说明》第 1 页明确：锁定款与普通款的主要区别是**接收器多一个隐藏按键**，用于配对锁定/解除配对锁定；其余使用方法及例程相同。图中红箭头指向接收器壳体的小针孔，附近另有较大圆孔。这里说的是接收器的按钮，不是手柄 MODE，也不是转接板上的未知焊盘。

辨别时先查看接收器壳体两面清晰照片，和厂商图示及原订单型号对照。**只有一个小孔并不足以证明下面就是绑定键，不要往未知孔插针。** 资料没有给出可通用于所有批次的标签代码、序列号或手柄外壳识别规则；仅看手柄外观和闪烁快慢也不能可靠判断。还要核对它是否与当前接收器原配，不能只给手柄单独贴“普通/锁定”标签便认定可与任意接收器互配。

型号未确认时，可先完成供电与断电重启排查；普通款自动配对步骤不等于已验证锁定款能解除旧绑定。本文暂不指导操作未确认型号的隐藏按钮，不把厂商锁定款的专用锁定流程套到普通款。

## 最简单的重来步骤

下面先只验证无线配对，暂不让电机或舵机动作。

1. 断开两块 TB6612 的 **VM 正极**和三路舵机正极，支撑机构。关闭整车电源。若 USB、ST-Link 或其他设备仍向主控/转接板供电，也先断开这些供电来源。
2. 手柄拨到 **OFF**，取出两节 7 号电池。接收器转接板也完全断电，确认指示灯熄灭；等约 10 秒再开始。这里的 10 秒是排查时的建议等待，不是厂家公布的恢复出厂时间。
3. 在断电状态下，将接收器的 **DAT、CMD、CS、CLK 四根信号线**暂时与 STM32 断开。这样能排除主控信号或信号线反向供电。接收器插紧在转接板上，按丝印供电。
4. 仅给**本项目已确认带稳压的转接板输入**提供稳定 **5V 和 GND**，不是给接收器内部裸电路随意接 5V，更不能接 12V。不需要先运行 STM32。手柄此时保持关闭。
5. 接收器进入待配对。给手柄装回电量充足、方向正确的电池，附近先只开这一套手柄和接收器，再将手柄拨到 **ON**。普通无锁款应自动搜索并配对，不需要按隐藏键或长按 MODE。
6. 按下表核对灯态。若手柄因等待超过 30 秒进入睡眠，按一下 **START** 唤醒再观察。
7. 无线配对通过后，先断电，再恢复四根信号线。启动新 A 板手柄程序，必要时按 **MODE/ANALOG** 切换模拟模式；本项目运动逻辑需要读取到 **`0x73`**。仅有灯亮不等于主控已正确读取按键。
8. 初次联调先保持电机和舵机供电断开；完成板间链路与手柄读取检查后，再按主指南分阶段试动作。唤醒用的 START 同时也是本项目停止键，唤醒或重连后仍需摇杆回中，再按 SELECT 解锁。

若完全断电后仍有接收器灯亮，说明存在其他供电路径，不算完成断电重启；不要继续带电拔插。

## 厂家明确给出的灯态

以下来自普通款手册第 4 页，按**红色电源灯 / 绿色信号灯**描述；不同转接板的 POWER、RX 丝印不能在未确认颜色和功能时直接代入。

| 场景 | 手柄 | 接收器 |
| --- | --- | --- |
| 手柄开启，尚未搜索到接收器 | 红灯或绿灯快速闪烁 | 依接收器是否供电而定 |
| 接收器只供电、四根信号线未接，手柄未开 | 关闭 | 红灯常亮，绿灯快速闪烁 |
| 已配对，接收器仍只供电、没有主控读取 | 两个指示灯常亮 | 红灯常亮，绿灯慢闪 |
| 已配对，已接主控并运行读取程序 | 配对成功时两个指示灯常亮 | 两个指示灯常亮 |

厂家第 12 页还建议：STM32 例程使用 MODE 调到手柄红绿灯都亮的模式。**最后仍以程序读到的模式和有效数据为准**，不要只凭指示灯判断 `0x73`。

此前“RX 常亮、POWER 闪烁”与上述红色电源灯应常亮的说明不能直接对应，当前尚未实物验证。它既不能证明配对正常，也不能仅凭这一点断定接收器损坏。

## 没成功时，按顺序区分问题

1. **供电**：先保持四根信号线断开，只保留正确的电源和地。核对实际转接板丝印、插接方向、电池电量、接头松动；用直流电压档检查转接板输入是否稳定。电源灯反复闪烁、全部灯周期重启或插上信号线才亮，都应先排查供电/反向供电，不要反复尝试所谓重置组合键。普通万用表读数稳定也不能排除瞬间压降。
2. **无线**：在供电稳定且主控信号线隔离时，按自动配对流程观察。未配对 30 秒会睡眠，按 START 唤醒；已配对后 5 分钟无按键也会睡眠。附近其他套装先关掉便于排查。厂家未在此手册保证不同批次、不同厂家的手柄和接收器可以互配。
3. **主控读取**：无线能配对、接上主控仍无有效输入时，再检查四根信号线和共地。新 A 板是 **DAT→PB14、CMD→PB15、CS→PB12、CLK→PB13**；不要用本手册其他示例的 PA4-PA7 去改接当前固件。
4. **模式**：`0x41` 是数字模式，不是无线失配的证明；按 MODE 切换到可读取 `0x73` 的模拟模式。本项目也不接受 `0x79` 压感帧作为当前运动输入。配对与切换模式是两件事。
5. **仍不配对**：记录两端具体灯的颜色、快闪/慢闪、供电测值、接收器/手柄型号及是否原配，留给下一轮排查。暂时没有可靠的普通款清绑定指令可继续尝试；需要厂商针对该实物型号给出支持流程，不能用锁定款或其他品牌的经验替代。

## “重置”到底指什么

| 操作 | 已核实的作用 | 不能据此声称 |
| --- | --- | --- |
| 两端断电再上电 | 重新启动手柄/接收器，普通款重新搜索和自动配对 | 已清内部绑定、已恢复出厂参数 |
| START | 厂家说明的休眠唤醒；本项目中同时是停止锁定 | 接收器清绑定或恢复出厂 |
| MODE/ANALOG | STM32 例程中切换手柄模式，需核对 `0x73` | 重置无线射频配对 |
| 重启 STM32 或调用 `ps2_init()` | 本项目函数只初始化 GPIO，后续发读帧请求 | 给未断电的接收器完成硬复位、清绑定或强制模式协商 |
| 本项目调参模式恢复默认/保存 Flash | 修改机器人 A 板配置 | 修改手柄或接收器内部配置 |
| 锁定款隐藏按键流程 | 该流程属于另一种产品的功能 | 已验证可用于当前普通无锁款 |
