# USB下载与第三路开门舵机

## 2026-10-18：双板已更新，USB下载通过；舵机动作待验

STM32新增8KiB USB loader候选版，PID APP搬到 `0x08002000`，末尾2KiB校准区保留。首次ST-Link安装，以后BOOT0=0、BOOT1=1并复位，用板载USB下载CRTCDFU1封包。文件区分、供电和恢复流程见 [loader说明](../firmware/stm32-usb-bootloader/README.md)。本轮用户确认电池未接；已用ST-Link首次安装、USB整包更新通过。读回APP匹配，末尾校准区不变，复位后VTOR=0x08002000、UART连通且输出禁止。ESP已写入v3并核对INFO；未发电机/舵机动作命令。

ESP32仍运行同一常规BLE/UART/回传固件，增加第三路LEDC，不新增开门专用固件，底盘往复测试仍在Dashboard。新构建身份 `crtc-lower-pid-servo3-v3`。

| 舵机 | ESP32-S3信号 | LEDC通道 | 软件范围 |
| --- | --- | --- | --- |
| DS3128大臂，位置型 | GPIO12 | 0 | 1300–1700μs |
| MG995小臂，位置型 | GPIO13 | 1 | 1300–1700μs |
| MG995开门，约90°行程 | **GPIO14** | **2** | **1000–2000μs** |

门舵机信号接GPIO14，负极接舵机电源GND并与ESP32共地；正极用符合实物额定规格、能承受其负载电流的独立稳压电源。不能接12V/3V3，也不默认由主控5V针承担三舵机电流。按实物标注辨认线序。

桌面/手机均有第三路启用1500μs、±10/25微调、释放，以及开门/关门/停止门。关1000μs、开2000μs只是约90°的**参考行程**，不是实测角度。先托住门、脱开机构，逐步校准端点和方向，避开机械限位；可交换开关值或缩小范围。勾选供电/支撑和已校准端点后才能启动；修改端点会清确认。端点仅保留当前页面，不写Flash，刷新后重新确认。

门由网页每次最多25μs、间隔至少150ms移动。ESP32每路强制至少100ms、首次只允许1500μs，三路独立记录；上电全为零占空比。移动期间禁止其他舵机命令和底盘解锁。STOP/断联/会话改变/过期状态/页面失焦隐藏取消后续动作，不自动续跑。已发一步不能撤回，舵机保持最后已接受脉宽；停止不代表轴瞬停，释放可能下垂。没有轴角反馈或门限位传感器，不能判断实际到位。

BLE opcode8新增byte12通道2；原session/sequence/防重放、四轮停稳和锁定门控不变。新增status kind5：byte2三路启用位，byte3 bit0可用、bits1–3位置掩码，bytes4–7=session，8–13三路小端脉宽，14–15门最小1000，16–17门最大2000，18–19最大单步25；固件最小间隔固定100ms。新网页仍读旧kind4两路状态，但禁用第三路；新ESP默认kind5，旧页面需升级。Agent servo接口通道为0/1/2，仍走既有确认和门控。

接线HTML保留原样式，添加 `GPIO14 → MG995门S`，不猜测未确认的物理排针位置。

验证：三路桥接/范围/独立状态，72项网页逻辑，两个离线DOM启动，11项接线编辑器/路由测试通过；STM32直烧/USB版、ESP32编译通过。UBSan未运行。USB枚举/下载/复位启动已通过；MG995门角度、端点、限位与带载仍待实测。

三路均有角度滑块，拖动仅替换最新目标，网页以≤25μs/150ms平滑跟随，不堆积拖动事件。大臂参考144–216°、小臂72–108°是原1300–1700μs首测窗口按标准500–2500μs换算；不自动扩大至全行程。门参考0–90°按当前开/关端点映射。角度都不是实测，需机构标定。三路共用单写队列，移动时不允许另一路抢占，STOP/失焦等取消后续动作。
