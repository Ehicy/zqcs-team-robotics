# 2026-10-23 胶轮底盘快起快停版（已构建，未烧录）

- 当前硬件：常规四胶轮差速，C3+STM32，一块STM32控制两块TB6612。轮序M1右前、M2左前、M3右后、M4左后；本次没有反转任何电机或编码器方向，用户自行修改的方向应从Dashboard保存配置重新写入。
- STM32：`stm32/dashboard-motor.hex` / `.bin` / `.elf`，ST-Link普通0x08000000应用，标记`0xC3D81023`；text17492、data16、bss1768。上电不启动车辆。
- C3：`esp32/`四段镜像，INFO为`crtc-c3-quickstop-v4`，舵机仍IO7/IO6/IO10，上电不回中。
- 两板必须配套更新。新STM32 UART状态增加0x20快停能力位；旧C3不识别扩展状态，不能混装测试。
- PID预置Kp=1、Ki=2、Kd=0立即可用，四轮独立计算；普通STOP/重握手不抹掉预置，C3空闲时自动同步系数。没有可信反馈时保留前馈，不因编码器掉线锁整车。标定confirmed仍为0，这些参数不是实车调优结果。
- 正常启动为约200ms五次S曲线。松键/空格/STOP优先发送独立一次性停止帧；先撤驱动10ms，再最多30ms制动。可信本轮测速仍同向时反推至多5%，且不超过刚才本轮PWM；近零速/缺少可信反馈采用TB6612短路制动，反馈过零反向立即结束。换向先短促制动，再曲线起步。
- 制动绕过PID，重复STOP不延长窗口，过期不补播。串口/会话/租期异常直接撤驱动并取消制动。40ms为软件窗口，不保证整车40ms停稳、不等于限流；未进行实车运动验收。
- Dashboard：`http://127.0.0.1:8080/dashboard.html?v=quick-v4`；根据C3+STM32能力回传显示已识别或待烧录，不把刷新网页当成安装固件。
- 验证：131项Node测试、四次离线真实ES模块DOM启动、V8接线图DOM测试；C3/PA/预置PID/快起停主机测试通过，旧协议/电机/PID/速度/手柄/编码器/双STM回归通过，历史lower-motor编译通过。Windows `SANITIZE=0`，未运行UBSan；仿真不是实车标定。

烧录命令准备：`firmware/tools/flash_c3_dashboard.ps1 -Port COM9 -PlanOnly`可只读查看C3计划；实际端口需重新枚举。此目录尚无安装记录，未发送运动指令。
