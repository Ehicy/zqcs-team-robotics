# 舵机照片适配 v3 — 2026-09-21

根据项目`pic/`中的8张实物尺照微调v2，保留原料仓、臂长及三个工作姿态。使用SolidWorks 2026生成原生零件、装配及STEP；v2保留。

## 照片依据

MG995：`197`长向及安装耳、`198`高度、`199`端部及标签、`200`宽向。SG90：`201`长向、`202`高度及标签、`203`耳孔、`204`宽向；编号对应文件名倒数第二组数字。两只标签均为TIANKONGRC，分别写MG995和SG90 ANALOG。

尺子与物体存在距离和透视差；以下取整用于拟合外形，不当作卡尺测量结果。

输出轴建成光圆包络，未打印或复刻花键；实际使用原装舵盘。照片没有给出可确认的舵盘孔距，因此不据此冻结联轴器舵盘孔。

## 修改内容

- MG995补安装耳、四个参考孔、上盖凸台和输出轴；修正朝向，让输出轴朝向臂根联轴器。
- MG995支架横向位置从Z48改为Z53，使支架面Z59与安装耳面相接；支架脚深24改为17，落在原底板宽度内。
- 同步底座孔：轴承支架脚孔为X±20/Z±14；舵机架脚孔为X=-9、31/Z=57、66（X相对臂轴）。底盘原板安装槽位置仍待核对。
- 仓前角避让槽随MG995安装耳和支架位置扩大为17mm横向宽、58mm高，保持其余仓体尺寸。
- 原夹爪方块占位换为SG90外形，新增3mm厚托架，窗口23.8×12.8，耳孔用2.4×4调整槽。
- SG90位于腕部侧面，壳体与腕部垫块之间留出空间。托架至腕部的连接件、原装舵盘至夹指的连杆尚未完成；现有夹指仍是动作外形，不是已驱动夹爪。

## 使用与验证

打开`FlipArm_V3_deposit.SLDASM`看投料；另有pickup、raised装配。保留同目录所有SLDPRT，或使用单文件STEP。`V3_REF`为采购件参考外形，不是打印零件；`V3_08_SG90_mount`为安装托架草案。

`build.ps1`用Windows PowerShell运行，`build.cs`是当前生成源码。重建读取本目录中从v2复制的其余零件，仅生成已修改零件及三个装配；会覆盖当前输出，先备份。`prepare.py`用于从v2重新生成源码，不应覆盖后续手动修改。

查看`build-log.txt`的实体数量、特征错误与导出结果，`*.png`为SolidWorks视图。软件检查不等于完整运动干涉或载荷验证。料仓内180×143×80、底68、沿148；臂轴110、臂板孔距130保持原值。
