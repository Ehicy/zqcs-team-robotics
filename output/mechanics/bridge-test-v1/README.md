# 150mm桥面通行试验模型

用途：验证现有轮胎外侧间距大于150mm、内侧间距小于150mm的底盘能否靠部分胎面稳定通过。不含两端高台、支架或护栏。不是官方场地精确复刻，也不是承载强度已验证的打印设计。

## 文件

- `Bridge_TEST_300x150_R15_T10.SLDPRT`：SolidWorks 2026原生实体，圆弧截面草图＋150mm拉伸。
- 同名`.STEP`：精确曲面交换文件，优先用于后续CAD加工。
- 同名`.STL`：毫米网格，已核对外包络300×150×25mm；竖直方向在CAD中为Y，切片时旋转并落到平台，切勿缩放适配打印机。
- `preview.png`：SolidWorks导出的模型视图。
- `build.cs` / `build.ps1`：参数及重建脚本。Windows PowerShell运行`powershell.exe -NoProfile -File .\build.ps1`，需要安装SolidWorks 2026。重建会覆盖本目录同名导出文件；修改前备份。
- `verification.txt`：实体数量、特征错误、极值坐标和导出结果。

## 尺寸依据与边界

本地《CRTC2026规则文档v1.0》第15页：单段长300mm、宽150mm、净高130mm、矢跨比0.05。b4/c4两段相接，另一侧f5/g5两段相接。本文件只做一个300mm模块，不能用单段测试替代整条桥的连续通行。

| 参数 | 本版取值 | 性质 |
|---|---:|---|
| 长度、宽度 | 300、150mm | 规则明确数值 |
| 起拱 | 15mm | 按单段跨度300×0.05计算 |
| 纵向曲线 | 圆弧，半径757.5mm | 试验假设，规则未明确圆弧/抛物线及弧线对应位置 |
| 板厚 | 竖直厚度10mm | 试验假设，不是规则尺寸，不是等法向厚度 |
| 下弧拱顶位置 | Y=130mm | 暂把净高解释为下弧中央净高，仅作坐标参考 |
| 下弧端部/上弧端部/上弧顶部 | 115/125/140mm | 上述假设的计算结果，不代表正式桥面标高 |

规则另有“占据1×2单位区块”与单段300mm的表述，以及连接300mm高台的描述，现有示意图不足以唯一确定桥梁截面、整桥弧线及端部标高。尤其不能把本版上表面140mm当作官方桥面高度，也不能以本版推定下层车过桥净空。应取得官方场地CAD或尺寸答疑后再修订。

## 最小试验

1. 固定两端、低位测试，轮外侧悬空处不能被桌面托住；确认桥板不明显变形。外部支撑不包含在CAD内。
2. 居中缓慢前进、后退，再左右各偏移5mm重复，记录掉边、打滑或需要频繁纠偏。将来仍需整条桥和入口过渡测试。
3. 以轮胎内侧净距g作简化计算，居中时每侧名义搭接为(150−g)/2；偏移d时较差一侧变为(150−g)/2−|d|。例如g=130mm，居中每侧10mm，偏移5mm只剩5mm。此数值不是麦轮滚子的有效接触宽度或稳定保证。

优先使用STEP在切片软件中细化曲面。若打印机放不下300mm，需后续分段并设计不影响行驶的接缝；不要把模型缩小。打印表面与正式场地材料摩擦不同，成功只能作为保留底盘的初步证据。
