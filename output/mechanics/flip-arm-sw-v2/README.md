# 翻转臂与料仓装配草案 v2

在SolidWorks 2026中建立可编辑零件，输出夹取、抬升、投料三份固定姿态装配及STEP。旧v1保留。当前是空间布局与接口草案，夹爪是占位外形，未建立SG90驱动连杆、运动配合或整车收拢姿态，不作为整套可直接打印装车的完成件。

## 本版参数（mm）

| 项目 | 数值与依据 |
|---|---|
| 底盘 | 用户提供255.8×149；板厚3、上表面离地35暂作占位 |
| 车轮 | 用户提供外径60；宽28、位置为占位，未复刻麦轮滚子 |
| 电控空间 | 150×90×25包络，放在底盘与仓底之间；不是具体电路模型 |
| 料仓 | 内180×143×80，侧壁和底板厚3，外长186、宽149 |
| 仓底/仓沿 | 内底离地68、仓沿148，沿用叠层估算，不额外叠加裕量 |
| 臂轴 | 距车头35，离地110；支架从离地40起高70 |
| 臂板 | 两片，轴至腕部孔中心130，主体宽22、厚6 |
| 名义夹持中心 | 臂轴至方块中心150，含暂定夹爪伸出20 |
| 舵机 | MG995主体40.5×20×39.5，来自用户商品截图；安装耳、轴位置和舵盘孔仍为参考值 |
| 支承 | 5mm钢轴、两只625ZZ轴承的参考方案；不是打印轴或打印轴承 |

世界坐标X从车头向车尾，Y向上，Z为横向。料仓位于X=69.8…255.8，后部和侧部用于接料，收集网暂不加入。容量目标12–16块；整齐排列每层4×3=12块是几何计数，不等于散装验证结果。

仓前板靠舵机支架处增加8mm宽、从仓底外表面向上58mm的局部避让槽，避开现有支架前角；不改变后方和侧方接料口。该槽不是供40mm方块通过的开口。

## 三个姿态

| 文件 | 臂角（相对向后水平） | 方块中心X/Y |
|---|---:|---:|
| `FlipArm_V2_pickup` | 216.87° | -85 / 20 |
| `FlipArm_V2_raised` | 90° | 35 / 260 |
| `FlipArm_V2_deposit` | 60° | 110 / 239.9 |

夹取至投料的名义转角156.87°；并非舵机已校准的脉宽或实际行程。夹爪姿态随臂旋转，方块为40mm实心包络，用于检查空间，不替代官方镂空块。

投料姿态方块X投影约83.75…136.25，位于仓内X=72.8…252.8范围，最低点约213.66，高于仓沿148。臂板在仓前沿处的下边缘计算高度约148.28，属于接近相切的布局；需要实际夹爪确定后再调整。这是选定姿态的解析检查，不是连续运动干涉检测或物理仿真。

## 文件使用

- 优先打开`FlipArm_V2_deposit.SLDASM`看整体，所需SLDPRT必须保留在同目录。组件固定在各展示姿态，不能当成已约束运动机构拖动。
- 三个同名STEP为独立交换文件。`V2_01`至`V2_07`是机构草案零件，`V2_REF`开头为采购件或外形占位。
- `build-log.txt`记录各零件实体数量及导出结果；`*.png`为SolidWorks实际视图。
- 参数和几何在`build.cs`，通过`powershell.exe -NoProfile -File .\build.ps1`重建；操作前备份。`prepare.py`从旧v1生成初稿源码，会覆盖build.cs，后续修改应以build.cs为准。

尚需完成的加工接口：底盘安装孔、支架与底座孔位配套、舵机耳及舵盘、轴向限位、实际夹爪连接。此次未核定初始260×190×200mm收拢包络、满仓过桥、载荷强度、电控实际高度或真实车轮外宽；不能把展示姿态当作已通过这些检查。
