# 队伍提供的下层车机械模型（2026-10-17）

本目录保存队员提供的 16 个 SolidWorks 零件文件和 1 个装配文件，原名、版本后缀及二进制内容均保持不变。逐文件大小与 SHA-256 见 `manifest.json`，归档时已与提供的原件核对一致。

优先在 SolidWorks 中打开 `装配体1.SLDASM`，并保留同目录所有 `.SLDPRT` 文件。若提示缺失参考文件，需要机械负责人提供打包（Pack and Go）结果；本次未在 SolidWorks 中解析装配引用、重建或检查干涉，不能据文件齐全认定装配完整。名称中的 2/3/4 仅为原始命名，不擅自判定哪一版最终用于装配，也不删除较早版本。

用户另行测量的当前车体参数：前后轮中心距 130mm、左右轮中心距 165mm、整车长×宽 240×190mm、轮径 65mm。这些数值来自实物测量，不是从本目录模型提取；机构展开包络、舵机转角和机械限位仍需核对。

两个舵机用途由用户确认：DS3128 用于大臂，MG995 用于小臂。当前信号分配：DS3128 大臂接 ESP32 GPIO7，MG995 小臂接 ESP32 GPIO5；本次没有分配夹爪舵机。均为预留接口，尚未实现 PWM 驱动；具体转角版本、脉宽和机械限位待核对。接线见 [整车接线说明](../../../docs/lower-car-wiring.md#板间通信与舵机预留)。

这些文件是用户提交的队伍机械设计资料，不将旧 `flip-arm-sw-v*` 草案自动视为本次装配依据。文件来源为本队用户提供；不擅自为其中可能引用的采购件模型声明新的开源许可。
