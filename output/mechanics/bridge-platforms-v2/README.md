# 带两端高台的桥梁试验装配 v2

用户要求在原试验桥上增加高台。原v1文件保留。本装配由两座300×300×300mm高台、两段300×150mm试验桥板组成；整体长1200mm、宽300mm、最高315mm。

桥板两端上表面与高台上表面均为Y=300mm，单段中部315mm。桥板沿用v1圆弧起拱15mm、竖直厚度10mm的假设，整体上移175mm。两段相接处无高度落差，但曲线切线不连续；这种两段起拱形状没有得到官方CAD确认。

规则第15页明确高台单模块300×300mm、高300mm，并说明b4/c4两桥段相连。本模型的接收端只画一个高台模块，不包含中央四模块高台、坡道或其他场地设施。

**这是通行试验装配，不是官方桥梁的精确复刻。上移后桥下空间不满足此前按拱顶解释的130mm净高，不能用于下层车、料仓的桥下净空验算。** 本版以桥面与300mm高台无台阶连接为优先；官方截面、130mm净高含义和整桥曲线仍待核实。

## 使用

- `Bridge_with_platforms_TEST.SLDASM`：SolidWorks 2026装配，4个固定组件。必须与两个SLDPRT依赖文件放在同一目录。
- `Bridge_with_platforms_TEST.STEP`：单文件完整几何，便于其他CAD软件打开。
- `Platform_300x300x300.SLDPRT`和`.STEP`：高台单件；它是实心占位几何，不是建议实心打印的加工设计。
- `Bridge_segment_for_platforms.SLDPRT`：桥板依赖文件，装配位置由组件变换确定。
- `preview.png`：SolidWorks实际视图。
- `verification.txt`：生成校验记录，4组件，导出无错误。
- `build.ps1` / `build.cs`：可重建模型的源码，使用Windows PowerShell和本机SolidWorks 2026。重建会覆盖输出文件，应先备份；依赖上一级bridge-test-v1目录中的桥板源件。

实物试验还需设计桥段连接与支承，CAD中端面相接不代表已具备承载连接。为避免大量打印，高台实物可用尺寸合适的刚性箱体制作；第一轮可先降低离地高度试跑，但保持150mm桥宽和入口过渡尺寸。模型没有验证结构强度或行驶稳定性。
